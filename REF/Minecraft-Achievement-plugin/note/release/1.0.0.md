# 1.0.0（2026-08-22）

首个版本。

## 功能

- 作为 **Paper 插件**（paper-plugin.yml + bootstrapper）通过 Datapack
  discovery API（`LifecycleEvents.DATAPACK_DISCOVERY`）将 jar 内置数据包注册为
  `ExampleAchievements/provided`，在原版进度界面新增独立标签页「示例成就」
  （命名空间 `exampleach`）。
- 7 项示例成就（名称为虚构）：
  - 你好，世界！（首次加入服务器）
  - 愚公移山（累计挖掘 200 个方块）
  - 干饭人（累计进食 30 次）
  - 为民除害（击杀 30 只敌对生物）
  - 姜太公再世（钓上 10 条鱼）
  - 平流层观光客（抵达 Y=300）
  - 大满贯！（集齐上述全部，挑战框架 + 隐藏 + 100 经验奖励）
- 成就由插件侧 `AdvancementProgress#awardCriteria` 授予（JSON 全部使用
  `minecraft:impossible` 触发器），弹出原版 toast，并以
  `PlayerAdvancementDoneEvent#message(Component)` 全服中文播报 + 音效。
- 玩家计数（挖掘/进食/击杀/钓鱼）以 `progress.yml` 持久化，脏位 + 定时落盘。
- `/exampleach`（别名 `/each`）查看个人达成进度，经
  `LifecycleEvents.COMMANDS` + `BasicCommand` 注册；阈值可在 `config.yml` 配置。

## 技术

- Java 21（`maven.compiler.release=21`）、Maven、
  `paper-api 1.21.11-R0.1-SNAPSHOT`（provided）。
- 数据包元数据使用 1.21.9+ 新式 `min_format`/`max_format: 94`（1.21.11），
  成就目录使用单数 `advancement/`。
- 适配 1.21.11 API：`PlayerAdvancementDoneEvent`（新名）、adventure `Key`、
  paper-plugin.yml 必填 `api-version`。

## 验证

- Paper 1.21.11 build 132 冒烟测试通过：1592 项进度全部解析（vanilla 1584 +
  本插件 8）；`/datapack list enabled` 含 `ExampleAchievements/provided (plugin)`；
  首次启动自动启用；`/exampleach` 控制台正确回显；停服进度保存正常。

## 已知限制

- 阈值启动时读取；跨 MC 版本需同步调整 pack.mcmeta 的 min/max_format。
- 未接真实客户端做玩家侧 UI 验证（依赖原版根进度 tick 授予机制）。
