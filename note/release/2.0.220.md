## 内容

### 循环 158：画布状态行「已选 N 项」

- 框选/Ctrl+加选多个节点、连线准备批量删除或对齐时，界面上
  此前没有任何数量反馈——选了几项全凭目测。状态行（图类 ·
  节点 · 连线 · 缩放读数一行）现在在有选中时追加「已选 N 项」，
  Esc/点空白取消选择即消失（不占位）。
- 代码侧状态栏「已选 N 字符」（循环 68）的画布同款；计数含
  节点与连线（Selection 双类）。
