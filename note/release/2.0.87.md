# 2.0.87

> 发布日期：2026-08-20
> 主题：取消可视化编辑器内嵌预览，改为页面级「对比模式」三栏布局

## 变更

- **取消内嵌实时预览**（2.0.86 的 `VisualPreview.svelte` 已删除）：可视化
  编辑器回归纯交互画布，不再自带第二套 Mermaid 渲染
- **新增对比模式**：可视化工具栏「对比」开关（默认关闭，偏好持久化
  `visualEditorPreview`）——开启后布局为 **代码编辑器 ｜ 可视化画布 ｜
  Mermaid 预览** 三栏对照；预览栏直接复用页面右栏的同一 `View.svelte`
  组件与渲染管线（含 panZoom 工具栏），画布编辑经状态网关发布后与预览面板
  同步刷新
- **纯模式保持默认**：可视化开关打开时即「代码编辑器 ｜ 可视化画布」两栏，
  无任何预览元素；移动端隐藏对比栏
- 编辑页以 `viewPane` snippet 复用预览栏两处渲染（纯编辑态 / 对比态），
  消除布局重复

## 测试

- e2e「compare mode shows the real mermaid preview beside code and canvas」：
  默认无预览栏 → 开对比后三栏且 Mermaid 渲染可见 → 画布加节点实时反映到
  渲染 → 偏好跨重进持久化
- 全量 e2e 47 通过 / 3 预存 skip / 0 失败；压测 stress-smoke 7/7；
  svelte-check 0/0；eslint / prettier 通过
