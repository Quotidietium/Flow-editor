## 审计结论

**导出链资源生命周期（高频连击视角）**：

- 全部文本导出走 data:URL（无 objectURL，零泄漏）；插件二进制导出的
  blob URL 5s revoke（同步 click 下载后回收，足够且不早收）；插件模块
  加载 blob 10s revoke（已加载实例不受 revoke 影响）；exporting 锁精确
  覆盖需要 panZoom 往返的五种异步格式（PNG/copy/WebP/JPEG/PDF），文本
  类同步导出正确地不加锁——无死锁面、无泄漏面
- registry loadModule 的 blob 子模块再引用理论边界（插件内部惰性
  import 相对路径在 revoke 后会失败）记录为已知取舍：示例与文档均不
  鼓励插件内相对导入

**History 恢复 → Visual 交互**：restoreHistoryItem 经
`replaceInputState` 状态网关（红线 1 ✓）；Visual 的外部代码 effect 在
恢复后触发 `loadFromCode` 重建画布并**清空撤销/重做栈**（跨外部状态
替换的 undo 属未定义历史，2.0.93 起的正确语义）；行内编辑/面板状态
一并复位。新增此前缺失的 e2e 全链路钉死：图 A 手动存历史 → 换图 B →
历史面板恢复 A → 画布即时显示 A 的节点（Gamma 消失/Beta 回归）且
撤销按钮禁用
