## 新增（参考 Visio / draw.io 交互规范，来源见 visual-editor-ux-design.md §7）

- **多选与批量操作**：Shift/Ctrl+点击加选/减选；空白处拖拽橡皮筋框选
  （默认全包围语义，按住 Alt 放宽为相交）；多选批量拖拽（保持相对位置）、
  批量删除；Ctrl+A 全选；锚点手柄仅在单选时显示
- **撤销 / 重做**：Ctrl+Z / Ctrl+Shift+Z / Ctrl+Y + 工具栏按钮（栈深 50）。
  采用 VGraph 整图快照而非文本 diff——避免把 mermaid 合法的往返归一化
  一并回滚；快照取自手势起点（拖拽 preState），命令类操作在变更前入栈；
  「从代码重载」清空历史（外部状态不可逆推）
- **剪贴板**：Ctrl+C/X/V 内部剪贴板（节点+其间连线；粘贴时 id 全部重铸、
  偏移 +24px 落点）；Ctrl+D 原位复制副本（draw.io Duplicate）
- **右键上下文菜单**（Visio 快捷菜单结构，画布/节点/连线分级 + 悬停子菜单）：
  - 节点：编辑标签(F2)/编辑内容/复制/剪切/复制副本/形状 ▸/类型 ▸/对齐 ▸
    （多选时 6 向对齐 + 水平/垂直等距分布）/删除
  - 连线：编辑标签/线型 ▸/反转方向（ER 基数同步对调）/删除
  - 画布：粘贴/全选/对齐网格/整理布局/从代码重载/清空
  - 监听以画布容器原生 contextmenu + closest 命中分发（不经 Svelte 事件委派）；
    Shift+F10 / Menu 键在选中项上打开
- **动态对齐参考线**（Visio 动态网格 / draw.io alignment guides）：拖拽时与
  未选中节点的左/中/右、上/中/下比对（容差 6px），吸附并显示贯穿参考线
- **键盘微移**：方向键 1px（Shift=10px）；与行内编辑/输入框焦点隔离
- 既有 Delete/Esc/F2/双击行内编辑保持不变

## 实现

- 新增 `src/lib/util/visualEditor/interaction.ts`（纯函数，16 项单测）：
  alignmentGuides / alignSelection（6 模式）/ distributeSelection /
  remintIds（剪贴板 id 重铸+边重指向）/ nodesInRect（框选命中）/ snapshotGraph
- VisualEditor：selected 单值 → 选择集合（主选=最后拾取者驱动单选工具栏）；
  拖拽批量化（delta 传播）；全部变更命令统一 pushUndo + 单次 syncCode 发布
- 性能红线保持：拖拽中零 gBCR（手势级缓存沿用）、参考线仅对未选中节点
  线性扫描、批量命令只触发一次状态网关发布

## 调试记录（重要教训）

- 本机 vite dev server 在文件改动后偶发不失效模块缓存（watcher 漏事件），
  导致服务旧模块（TID 常量缺失→菜单 testid 不渲染→误判功能失效排查了
  整条事件链）。**遇到"不可能"的 UI 行为先 curl 模块源码比对磁盘**；
  重启 dev server 解决
- e2e：拖拽密集用例与 trace 截图在本机有交互问题（渲染器冻结/断言超时），
  `trace: 'off'` + 拆分组合手势用例后稳定；功能行为另以独立复现脚本核实
