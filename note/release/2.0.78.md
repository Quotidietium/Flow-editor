# 2.0.78

> 发布日期：2026-08-20
> 主题：稳定性审计第 3 轮——渲染管线资源生命周期修复

## 新增

- **pan-zoom 资源释放**：`PanZoomState.destroy()` 销毁 svg-pan-zoom 实例（其持有
  window 级 resize 监听器）与 ResizeObserver 并清空变更回调；View 卸载时调用——
  此前每次 Visual↔预览切换泄漏一份监听器，长期高频切换累积（记忆的 pan/zoom
  保留，再次进入预览自动恢复视口）
- **视口恢复夹取**：从 URL hash 状态恢复的 pan/zoom（不可信输入）夹取到实例自身
  界限（zoom∈[0.2,12]、pan±1e6），与 2.0.77 的 embed 侧夹取对齐
- 复审通过（无需修改）：hammerjs 触摸监听随被替换的 SVG 元素回收；渲染 promise
  队列吞尾错为保活设计；组件卸载后排队任务安全短路

## 测试

- 新增 panZoom 生命周期单测（destroy 释放 observer/回调、幂等）
- 全量 e2e 42 通过 / 3 预存 skip / 0 失败；单测 163 通过（15 个本机预存失败与
  基线一致）；svelte-check 0/0；eslint 通过
