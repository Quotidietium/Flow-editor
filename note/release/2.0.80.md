# 2.0.80

> 发布日期：2026-08-20
> 主题：稳定性审计第 5/6 轮——迁移防御、历史上限、消毒深度、导出重入、重定向白名单

## 修复

- **迁移版本防御**：migrations 版本号（不可信 localStorage）负数/小数原先使启动崩溃
  （migrations[-4] 迭代 TypeError），超界值静默禁用未来迁移——范围校验 + 重置重跑
- **manual 历史上限 200 条**（淘汰最旧）：原先无限增长最终耗尽配额，编辑器持久化静默失效
- **消毒器深度护栏**：getUnsafePaths 超过 100 层嵌套的子树整体剥离（防 JS 栈溢出）
- **导出重入锁**：导出进行中禁用 PNG/SVG/复制按钮（双击原先产生并发导出竞态）
- **旧链接重定向路由白名单**：恶意 hash 路由段不再流入 resolve()，回落 /edit

## 测试

  全量 e2e 42 通过 / 3 预存 skip / 0 失败；单测 170 通过（15 个本机预存失败与基线一致）；
