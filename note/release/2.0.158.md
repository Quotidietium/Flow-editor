# 2.0.158

> 发布日期：2026-08-26｜分支：`develop`
> 主题：**WEB UI 舒适度优化循环 70–74**——版本号归真、示例数角标、
> 时序结构骨架、双击重命名、启动加载指示。

## 内容

### 循环 70：版本号显示应用自身版本（真修复）

- `VersionSecurityToolbar` 此前显示 **Mermaid 引擎库版本**（v11.x），
  用户报障会拿错版本号；现显示应用自身版本（根 package.json 编译
  期注入），引擎版本并入悬停 title。

### 循环 71：示例类目示例数角标

- 多示例类目的下拉触发钮带数量角标；角标数字 = 下拉项数（不变式）。
  初版放主钮内撞 fixture 的 `getByText(exact)`（aria-hidden 只影响
  可访问名不影响 DOM 文本），loadSite/actions 串行实证破裂，改放
  触发钮内并加双回归网。

### 循环 72：时序结构骨架三件套

- 插入菜单补 loop 循环 / alt-else 分支 / activate-deactivate 激活
  ——时序图最高频的三种结构，光标处插入不弹整图替换。

### 循环 73：历史条目名双击/键盘直达重命名

- 名称自身即重命名入口（`role=button`+`tabindex`+Enter/Space/双击
  全可达，MC 树行同款模式）；铅笔按钮保留为视觉发现路径。

### 循环 74：启动加载指示

- SPA 首屏水合前空白数秒（冷启动实证）——app.html 内置纯 HTML/CSS
  加载指示（明暗自适应、无 JS 依赖即显）；Svelte 挂载向 #svelte 追
  加而非清空（实测 splash 残留），配 MutationObserver 自移除：应用
  内容一出现即消失。
