# 2.0.127

> 发布日期：2026-08-22
> 主题：Windows 离线安装包（Electron + NSIS）——安装即用，零前置依赖

## 内容

新增 `installer/` 目录，一键产出单个 Windows 安装包
`Flow-Editor-Setup-<版本>.exe`：**最终用户无需安装 Node、pnpm 或任何
其他软件**，Electron（Chromium + Node 运行时）与完整站点全部内置。

- **方案**：`installer/app/` 内为 Electron 主进程（`main.cjs`）与内嵌
  静态服务器（`server.cjs`）。应用启动时在 `127.0.0.1:38527`（冲突顺延）
  伺服打包进 asar 的站点产物，BrowserWindow 加载 `/edit`。
  - 不用 `file://`：ES module 脚本受其 CORS 拦截；
  - 端口固定：`localStorage` 按 origin 隔离，origin 跨启动不变，
    草稿与历史时间线才能持久（冲突顺延、全占用回退随机端口并告警）；
  - 服务器具备 MIME 表、SPA 兜底（404.html）、目录穿越防护、
    immutable 资产长缓存、`Service-Worker-Allowed` 头。
- **安装包**：electron-builder NSIS 辅助向导，per-user 安装免管理员，
  简体中文界面，桌面/开始菜单快捷方式，卸载保留用户数据；`/S` 支持
  静默安装。图标由 `static/favicon.png` 生成多尺寸 `icon.ico`。
- **构建**：`installer/build.ps1`（PowerShell，UTF-8 BOM）编排：
  站点构建 → 产物/版本同步 → 依赖安装（直连失败自动回退 npmmirror
  镜像）→ 图标 → 打包 → 冒烟测试；工具缓存收敛在 `installer/.cache`。
- **冒烟测试**（`installer/scripts/smoke.mjs`）：对产物做真实全链路
  验证——静默安装、启动探测（`/edit`、immutable 资产、service worker、
  404 兜底、目录穿越防护）、静默卸载。
