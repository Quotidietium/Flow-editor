# 2.0.106

> 发布日期：2026-08-21
> 主题：第 19 轮审计——Monaco 双 model 生命周期 + initEditor 幂等性修复

## 审计结论与修复

**双 model 生命周期（审计通过 + e2e 强化）**：
`createModel`（internal://mermaid.mmd / internal://config.json）与
`dispose()` 在 onMount cleanup 中严格配对；editorMode 切换用
`setModel`（零新增 model）。跨界往返顺序（旧实例 dispose 先于新实例
create——同 URI 二次 create 会抛错）此前只有单向 e2e，本轮把移动边界
用例扩展为**往返**（桌面→移动→桌面→移动），Monaco 重挂载且携带相同
代码——dispose-before-create 顺序被钉死

**initEditor 幂等性（修复）**：Monaco 的语言/Provider 注册**不去重**，
而 DesktopEditor 每次挂载都调 initEditor——每次桌面↔移动跨界都会堆叠
一份重复的补全 Provider/主题/语言配置（长期会话内存与补全 CPU 单调
增长）。修复：模块级 once 守卫。新增单测（mock monaco-editor 计数）：
三次 initEditor 调用后 register/completion/config/tokens 各恰好 1 次
