# 2.0.90

> 发布日期：2026-08-20
> 主题：可视化编辑器 UX 第三批——正交连线路由、节点尺寸手柄、分组容器视觉

## 新增

- **正交连线路由**（draw.io 默认路由风格，P0 路线表最后一项）：
  - 新增 `src/lib/util/visualEditor/routing.ts` 纯函数路由器：按两端中心
    主导轴选择出/入端口，三段曼哈顿折线 + 8px 圆角拐点；中轴与节点盒
    相交时迭代外推避让（AVOID_PAD 26px，取距理想中轴最近的可清空选项）
  - 三种全局连线风格：直角（默认）/直线（原有）/曲线（二次贝塞尔），
    画布右键菜单「连线风格 ▸」切换，偏好持久化 `visualEditorEdgeStyle`
  - 边标签与 ER 基数沿路径按弧长比例定位（`pointOnRoute`，0.15/0.5/0.85），
    箭头沿末段方向自动定向；命中测试与视觉路径共用同一 `d`
- **节点尺寸手柄**：单选节点四角显示缩放手柄，拖动调整宽高（60–900 ×
  36–600，网格吸附）；尺寸为编辑器本地状态（`visualEditorSizes` 持久化 +
  白名单校验 + 100KB 护栏，与位置记忆同一通道，不进入生成代码）；节点
  右键菜单新增「重置尺寸」；detail 行数增长仍保证最小高度
- **分组容器视觉**（Visio Container 风格）：分组角色节点（看板列表、旅程
  分组、时间线时期、甘特阶段、Cynefin 域）渲染为虚线圆角容器——主题色
  淡填充、标题左上加粗、渲染层级先于普通节点（子项绘制在容器之上）
