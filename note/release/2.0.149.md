# 2.0.149

> 发布日期：2026-08-25｜分支：`develop`
> 主题：**WEB UI 舒适度优化循环 39–42**——移动端可视化工具栏单行横滑、
> 我的代码片段、/view 页 SVG 下载、导航栏明暗一键切换。

## 内容

### 循环 39：移动端可视化工具栏单行横滑

- 390px 实测 13 个按钮换行平铺要占 ~159px 画布高度（约 19% 屏高）——
  改单行 `overflow-x-auto` 横滑（sm 起恢复换行平铺），工具栏高度
  ≤64px，首尾按钮滑达可点，桌面零变化。

### 循环 40：我的代码片段

- 插入菜单新增「我的片段」区（与「我的配置模板」同形制）：当前代码
  一键存为具名片段（20 条/5KB/加载期白名单校验/同名覆盖），之后从菜单
  光标处插回——选区替换、不触碰文档其它内容；预览行展示首行压缩文本、
  悬停 title 见全文、可删除。

### 循环 41：/view 只读页 SVG 下载

- 分享链接接收者只有缩放工具、想存图必须绕道编辑器——页面右上加
  「下载 SVG」。`svgMarkupOf` 克隆现场图形并剥掉 pan-zoom viewport 的
  平移/缩放（`transform` 属性与 `style="transform: matrix()"` 两形态
  都剥——e2e 先抓到现场是 style 形态），补 xlink 命名空间、自闭合规整、
  `--background` 垫底；下载件呈现完整图形而非屏幕视角。

### 循环 42：导航栏明暗一键切换

- 明暗切换此前深埋在主菜单二层——高频操作给直达钮：太阳/月亮图标随
  目标模式切换、`aria-pressed` 状态、title 提示，持久化沿用
  mode-watcher 原生存储。
