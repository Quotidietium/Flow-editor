# 2.0.77

> 发布日期：2026-08-20
> 主题：稳定性与安全性审计（两轮）——不信任输入加固、发布管线竞态修复、死代码清理

## 数据安全修复（审计第 1 轮，commit 2a2f7658）

- **localStorage 配额异常不再中断编辑**：`writeJSON` 位于状态网关 `update()` 链内，
  配额满时抛异常会丢弃进行中的发布（长期运行真实风险）——改为尽力而为 + 警告
- **发布乱序竞态**：快速输入下慢的旧 `mermaid.parse` 后完成会覆盖新状态（编辑器与
  URL 停在过期图）——发布带序号，被超越的发布丢弃；测试经「去修复转红」验证有效
- **可视化解析器加固**：mindmap 生成改迭代 DFS（数千层缩进树原先栈溢出）；超长单行
  （>10k 字符）跳过计数（惰性量词二次方退化冻结页面）；`visualEditorLayout` 位置表
  白名单校验（NaN 坐标会传播到全部几何与 SVG 属性）
- **历史导入加固**：5MB 文件上限、解析失败 toast（原先静默 unhandled rejection）、
  单次恢复 200 条上限（原先可灌爆无截断的 manual store）、state 结构校验

## embed 暴露面与状态机（审计第 2 轮，commit 09c07536）

- `/embed` 的 `?pan/?zoom`（含 hash 状态携带）夹取到可用范围（原先 `1e308` 级数值
  产生病态变换）；embed-loader 复审干净（参数编码/CSSOM 赋值/origin 钉死）
- `autoSync` 渲染节流状态机补 4 个 fake-timer 测试（此前零覆盖的核心长期路径）
- 删除死代码 loading 全屏遮罩（`initLoading` 最后调用者已在 2.0.69 移除，遮罩永不显示）
