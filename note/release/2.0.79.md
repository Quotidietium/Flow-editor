> 主题：稳定性审计第 4 轮——分享链接解压炸弹防护

## 新增

- **serde 解压上限**：`pakoSerde.deserialize` 对解压后负载设 20MB 上限——手工构造的
  ~KB 级 deflate 炸弹可膨胀至 GB 并在任何异常处理前冻结页面；超限抛错并由调用方
  展示 URL 排查引导图（真实链接远低于上限，loadSite e2e 全过验证兼容）
- 单次 inflate + TextDecoder 解码（避免双重解压）；复审通过：service worker 为空
  pass-through，无缓存策略风险

## 测试

- 新增 serde 炸弹/正常往返双测试；全量 e2e 42 通过 / 3 预存 skip / 0 失败；
  单测 165 通过（15 个本机预存失败与基线一致）；svelte-check 0/0
