# 2.0.132

> 发布日期：2026-08-23
> 主题：MC 数据包逆向导入（打开 zip → 成就图）+ 插件 API 二进制/异步导入能力

## 内容

### 数据包逆向导入（mc-advancement 1.4.0）

「打开」接管 `.zip`，识别 MC 数据包布局或本插件导出的 Maven 工程 zip，
反推为成就图：

- **自家导出完整还原**：导出时在数据包根写入 `flow-editor.json` 溯源
  元数据（Minecraft 忽略未知文件），导入时触发器/参数/栏设置/全局设置
  无损恢复——导出→打开→再导出闭环成立（e2e 实测）。
- **外部数据包尽力还原**：parent 树/名称/描述/图标/框架/隐藏/toast/经验
  从 advancement JSON 恢复；impossible 条件无法反推触发方式 → 退化为
  「仅命令授予」；大满贯按条件集启发式识别；多命名空间取最大者并提示。
- zip 解析自包含（中央目录 + store 直读 + deflate 走
  `DecompressionStream`）；非数据包 zip 返回 undefined 放行内置解析器。

### 插件 API 能力扩展（平台层）

此前 **任何插件都无法导入二进制格式**（文本通道有损、handler 仅同步）：

- `fileIO.openTextFile` 改为 `arrayBuffer` 读取，`{name, text, bytes}`
  双通道下发；
- `import` 钩子支持 **async**（新增 `guardedAsync`——rejection 与同步
  异常同样三振隔离，不会逃逸成 unhandled rejection）；
- `ImportHandler` 类型/文档同步（`plugin-api.md` §2.2、`API.md` §7.1）。

### 修复

- fileIO 读取失败路径随 arrayBuffer 改造同步更新（原单测 mock `text()`
  → `arrayBuffer()`，语义不变）；新增 bytes 通道单测。
