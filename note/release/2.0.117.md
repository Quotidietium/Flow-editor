> 发布日期：2026-08-21

## 审计范围

本轮覆盖插件系统三个钩子的不可信面：inputTransform 管道输出边界、
export 钩子错误隔离、theme 插件 CSS 注入面。

## 缺陷与修复

**transform 输出无尺寸上限（修复 + 判别性单测）**：
`runInputTransforms` 对插件返回的字符串只验类型不验尺寸——管道输出
直入状态网关的同步 `JSON.stringify` + localStorage 写：恶意/缺陷插
件返回数 MB 字符串会冻结主线程并可耗尽存储配额。2.0.113 只给 bridge
**输入侧**加了 5MB 上限，管道**输出侧**无对应防线。修复：超限输出丢
弃（保留变换前的值），且不会级联进后续插件；console.error 记录。

plugins.test.ts 新增判别性用例：5,000,001 字符的 transform 输出被丢
弃、下一个插件收到的是原输入、错误日志含插件 id。判别性验证：暂存
修复套件失败、恢复后 14/14 通过。

## 审计通过项

- **export 钩子隔离**：`runPluginExport` 经 `guarded` 包裹（try/catch
  + 3 连错自动停用），调用方对 undefined 降级；payload 仅下载用不执
  行
- **theme CSS 注入面**：theme 声明即代码——插件本就是已授权执行的同
  源代码（manage-plugins 模式，无跨权限面）；variables 为 CSS 变量
  声明、css 文本域经 `<style>` textContent 注入（非 innerHTML，无
  标签解析逃逸）；幂等（同 id 覆盖）；disable/uninstall 时
  removePluginTheme 移除
- **transform 反值抑制**：`guarded` 同步 run，`undefined` 反值时
  保留当前值、不中断管道；throw 有隔离 + 三连停用
