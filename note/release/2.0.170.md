# 2.0.170

> 发布日期：2026-08-26｜分支：`develop`
> 主题：**WEB UI 舒适度优化循环 105–106**——移动端示例卡默认折叠、
> 个人资产备份（导出/导入）。

## 内容

### 循环 105：移动端示例卡默认折叠

- 编辑半屏 390px 实测示例卡占 296px（编辑器仅 364px，40% 高被吃）
  ——sm 以下 isOpen 默认收起，编辑器多得约 300px；展开仍可且
  persistKey 记忆用户选择（桌面默认不变）。

### 循环 106：个人资产备份（导出/导入）

- 三类「我的××」（配置模板/示例/片段）此前锁死在单浏览器
  localStorage——主菜单新增「我的资产备份」对话框：计数如实展示、
  导出 JSON 下载、filechooser 导入（结构白名单校验+同名覆盖合并+
  计数 toast）、清空本机需确认（建议先导出）。导入经
  `flow-assets-changed` 事件联动三处菜单重读 storage——**不刷新页
  面即见**（e2e 抓到的缺口：首版导入后菜单不刷新）。
