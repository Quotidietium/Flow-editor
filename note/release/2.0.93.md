## 变更（对 2.0.92 插件系统的完成度审计修复）

上一版文档声称输入管道触发于 `bridge`/`url`，但两处实际未接线。本轮补齐：

- **桥接写入接入输入管道**：`window.__FLOW_EDITOR_API__.setCode/setState`
  （即 MCP `set_code`/`set_state` 工具）现先经
  `runInputTransforms(code, 'bridge')`——AI/插件前端写入也过清洗/转换插件
- **URL 分享链接接入输入管道**：`loadState` 反序列化成功后应用
  `runInputTransforms(code, 'url')`。registry 经**动态 import** 引入，避免
  state 低层模块对插件系统的静态依赖环；`applyLoadedState` 提取为纯步骤
- **挂载顺序修正**：插件注册（`loadRegistry`）现先于 `initHandler`——
  首次带分享链接进入页面时 URL 管道即可见已安装插件
- **theme.css**：`theme` 钩子新增 `css?: string` 字段（与 `variables` 可任
  意组合）——任意 CSS 注入，覆盖**布局调整、背景贴图、字体替换**等
  CSS 变量表达不了的场景；停用即还原
