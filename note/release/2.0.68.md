# 2.0.68

> 发布日期：2026-08-19
> 主题：新增可视化图形编辑器（Visual Editor）

## 新增

- **Visual 标签页**（编辑页 Code / Config 旁）：Draw.io / Visio 式图形化编辑，实时生成 Mermaid flowchart 源代码
  - 双击画布建节点、拖拽移动（网格吸附）、锚点拖出连线、双击改文字
  - 节点形状循环（矩形/圆角/胶囊/菱形）、线型循环（箭头/直线/虚线）、方向 TD/LR、Delete 删除、自动分层布局、从代码重载、清空
  - 生成代码经 `updateCode()` 状态网关同步：预览、URL、localStorage 自动更新；进入标签自动导入现有 flowchart
  - 设计文档：[visual-editor.md](../visual-editor.md)

## 变更

- `Card/Tabs.svelte`：Tab 支持可选 `testID`（e2e 定位用）
- 编辑页标签切换逻辑：`activeTab` 本地状态管理，Visual 编辑器与 Monaco 常驻挂载（hidden 切换，状态跨标签保留）

## 测试

- 新增 `src/lib/util/visualEditor/model.test.ts`（15 用例：代码生成/解析/往返一致性/布局/锚点几何）
- 新增 `tests/visualEditor.spec.ts`（2 个 Playwright e2e：画布交互→代码生成→预览渲染→持久化全链路；现有代码导入→形状切换往返）
- 验证：单测 15/15、e2e 2/2、svelte-check 0 错误 0 警告、eslint/prettier 通过

## 已知问题

- 本机（Windows）vitest 预存失败：persist/migrations/state/historyState 等 localStorage 依赖测试 `window.localStorage` undefined（2.0.67 基线同样失败，CI Linux 通过，与本版本无关）
- 可视化编辑器仅支持 flowchart；subgraph 导入时忽略（详见设计文档「局限」节）
