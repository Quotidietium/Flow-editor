# 2.0.130

> 发布日期：2026-08-23
> 主题：MC 进度设计器 × 桌面版离线编译链——导出即可装入服务器的 .jar；
> JDK 21+ 由用户自行安装（版权红线，应用不捆绑/不下载 Java）

## 内容

### 桌面版离线编译链（mc_build）

2.0.129 的 MC 进度设计器导出 Maven 工程 zip 后还需本机 Maven + 联网拉
paper-api 依赖才能构建。本版本把编译链内置进桌面版：

- **链路**：插件前端「编译导出 jar」→ `CORE.buildJarRequest`（只取
  `src/main/java|resources`，并把 paper-plugin.yml 的 `${project.version}`
  置换为实际版本——javac 路径没有 Maven 资源过滤）→ 桥新工具
  `mc_build`（网页版固定返回「仅桌面版可用」）→ preload
  `__FLOW_DESKTOP__.mcBuild` → 主进程 `mc-build.cjs`：白名单校验 →
  定位 JDK → `javac --release 21`（内置工具链 classpath）→ jar 打包 →
  base64 回传 → 前端下载 `<插件名>-<版本>.jar`。`initialize` 经
  `capabilities.experimental['flow-editor/mcBuild']` 声明能力，前端据此
  显隐按钮。
- **工具链**（`installer/toolchain/`，随安装包 extraResources 分发）：
  javac 实测最小 compile classpath 共 12 个 jar（~6.6MB：paper-api +
  guava + brigadier + bungeecord-chat + slf4j + adventure×4 + examination×2
  - jetbrains-annotations）。`scripts/fetch-toolchain.mjs` 优先本机 .m2
    复制（构建机离线可用），缺失回退 repo.papermc.io；许可证经各项目官方
    仓库/pom 原文核实（GPL-3.0/MIT/Apache-2.0/BSD-3-Clause）写入随包的
    `THIRD_PARTY_NOTICES.txt`；不含任何 Mojang 代码/资产。
- **版权红线**：不捆绑、不自动下载任何 JDK/JRE。JDK 探测覆盖
  JAVA_HOME / Program Files 各发行版根（含 `latest/jdk-XX` 嵌套）/ scoop /
  PATH，要求 javac 与 jar 同目录配对（Oracle javapath shim 无 jar.exe 会
  被跳过）且主版本 ≥21；未满足时返回 `JDK_NOT_FOUND`/`JDK_TOO_OLD`，
  前端展示「请您自行安装 JDK 21 或更高版本（如 Eclipse Temurin）」引导。
- **安全面**：主进程复核全部输入（路径白名单、禁 `..`、条目/单文件
  1MB/总量 8MB 上限）；源文件仅作数据落盘、spawn 参数数组无 shell；
  工作目录 mkdtemp 用完即删；MCP 执行器超时 15s→60s（javac 冷编译）。
  API.md §13 新增第 12 条红线。
- 插件设置新增「版本号」字段（pom/jar 名/插件 yml 同源）。

### 踩坑记录

- electron-builder `extraResources.from` 相对**项目目录**（installer/，
  package.json 所在）而非 `directories.app`——`../toolchain` 被解析到
  仓库根而静默不打包（`file source doesn't exist` 仅日志警告），冒烟
  探针抓住；已改为 `toolchain` 并验证安装产物内含。
- `jar` 工具写数据描述符（本地头 csize=0）——解析产物必须走中央目录。
- Windows 上 `where javac` 命中的 Oracle javapath shim 目录没有 jar.exe，
  完整 JDK 在 `Program Files\Java\latest\jdk-XX\bin`（一层嵌套）。
