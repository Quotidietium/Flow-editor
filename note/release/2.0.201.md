## 内容

### 循环 139：差异行复制

- 对比对话框 footer 新增**「复制差异」**钮：产出 unified 风格差异
  片段（`- 旧行` / `+ 新行`，不含上下文行）——把「改了什么」直接
  贴进 issue / 聊天；无差异时按钮禁用。
- 提取纯函数 `diffToText`（lineDiff.ts）承载前缀与顺序语义，单测
  覆盖（前缀渲染 / 保留差异顺序跳过上下文 / 相同输入空串）。
- 与既有「复制左版/右版代码」「对调」「恢复左侧」同栏共存，footer
  三枚复制/恢复动作 + 顶部切换形成完整的对比操作面。
