## 内容

### 循环 130：一键直达双件套

- **配置 JSON 一键格式化**：配置模式编辑器卡操作区（模板菜单旁）
  新增格式化钮——手写的压缩/混乱 JSON 一键展开为 2 空格缩进
  （复用全局 `formatJSON`，与分享链接/配置模板产物同款格式）。
  解析失败不改动内容：错误横幅已提示语法问题，按钮 toast 引导
  先修复（错误态本就不可格式化，语义上只做成功路径）。
- **历史条目一键复制分享链接**：历史面板每条目新增复制钮
  （「在新标签页打开」旁）——链接本就由条目序列化好，分享某个
  历史版本从「新标签打开 → 复制地址栏」两跳变一击，toast 反馈。
- 两项均为既有能力的入口补全：格式化补齐配置编辑体验链
  （补全/括号着色/模板 → 格式化），复制链接补齐历史分享链
  （对比/恢复/新标签打开 → 复制链接）。
