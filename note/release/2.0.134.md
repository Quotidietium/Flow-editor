## 内容

### 战利品奖励（mc-advancement 1.6.0）

成就达成时除经验外可发放物品（1.21 advancement 语义：`rewards.function`
指向数据包函数；旧 `rewards.loot` 已在 1.21 移除）：

- **模型**：`nodes.<id>.loot = [{item, min, max, weight?}]`（frontmatter，
  随分享链接/快照自动携带）；空物品条目导出时忽略并警告；数量下限≤上限
  自动规整；权重默认 1（=1 时省略）。
- **生成**：每条有战利品的成就产出
  `data/<ns>/loot_table/<id>.json`（单池、条目=item+`set_count` 数量区间、
  可加权，表类型 `minecraft:chest`）与
  `data/<ns>/function/<id>.mcfunction`（`loot give @p loot <ns>:<id>`）；
  成就 JSON `rewards` 同时含 `experience`（若配置）与 `function`。
- **前端**：成就表单新增「战利品奖励」区——条目行（物品 ID/数量下限/
  上限/权重）增删改，物品 ID 提供图标 datalist 复用。
- **逆向导入**：外部数据包（无溯源元数据）从 `loot_table/<id>.json`
  反推条目（物品/数量区间/权重）；自家导出走溯源完整往返。
- **桌面编译链**：`mc-build.cjs` 路径白名单扩展 `.mcfunction`——战利品
  函数随 jar 打包（`datapack/function/*.mcfunction`）。
- 校验：战利品物品 ID 格式警告（复用物品 ID 正则）。
