# 2.0.159

> 发布日期：2026-08-26｜分支：`develop`
> 主题：**WEB UI 舒适度优化循环 75–77**——配置错误一键重置、卡片折
> 叠状态记忆、时间线 FIFO 规则进 UI。

## 内容

### 循环 75：配置错误横幅「重置为默认配置」直达钮

- 配置 JSON 损坏时横幅现场给一键恢复（与模板菜单重置同语义
  `defaultConfigJson`+`updateConfig`）——用户不必知道模板菜单里藏着
  该功能；只在 errorSource=config 出现（代码错误不给），双端可用。

### 循环 76：卡片折叠状态跨会话记忆

- 收起示例卡片专心作图（或常驻展开操作卡片），重载后保持——Card
  新增 `persistKey`（一次性 `untrack` 取初始值、切换即写回；不给
  key 的卡片行为不变）。示例/操作两卡启用，编辑卡恒展开照旧。

### 循环 77：时间线 FIFO 规则进 UI

- 时间线只留 30 条先进先出，此前只写在代码注释里——用户会以为旧
  版本「丢了」。卡片底部常驻说明：最近 30 条 + 指引重要版本收藏到
  「已保存」（200 槽位）。初版放 ul 内作 li 撞 `#historyList li`
  计数断言致两测试破，移出 ul 修复（循环 71 角标同款教训再现——
  新增 DOM 必须先想既有选择器）。
