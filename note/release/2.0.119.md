# 2.0.119

> 发布日期：2026-08-21
> 主题：非流程图可视化编辑重写（一）——分组列表族改用看板编辑器

## 背景

实际体验反馈：非流程图的可视化编辑交互极差。根因是 31 类图共用一套
「自由框线画布」——对非节点-边语义的图族，画布的隐喻完全违背用户心智
（饼图切片在画布上是漂浮的方框、看板列与卡片之间画着误导性的连线、
思维导图的层级要靠拖拽位置表达……）。

重写总方案：**按图族提供专用编辑器**，全部操作同一 VGraph 模型并经
`commit()`（= pushUndo + mutate + syncCode）单一网关发布——解析/生成层
零改动，撤销/重做/代码同步/URL 分享全部自动继承。`KindSpec.view` 声明
各类型的编辑器形态（缺省 = 原画布）。

本版本落地第一个：**看板编辑器（BoardEditor）**。

## 看板编辑器（journey / gantt / timeline / kanban / cynefin）

- **列 = 分组、卡片 = 条目**：分组节点渲染为列（journey 的 section、
  kanban 的 column、gantt 的 section、timeline 的 period、cynefin 的域），
  组内条目渲染为列内卡片；不再显示误导性的「结构连线」。
- **拖卡换列 / 列内拖拽排序**：HTML5 拖放；拖到卡片上 = 插入其前。
  底层 `moveCard` 重写唯一成员边（生成语义是「首条分组边生效」，多写一
  条会静默丢失归属变更）。
- **行内编辑**：列名、卡片名、卡片详情（journey 评分 `5: 我`、gantt 日期
  `2024-01-01, 3d`、kanban `@{…}` 属性尾缀）全部输入框即改即存
  （blur/Enter 提交一次 undo 快照）。
- **列操作**：添加列、重命名、左右移动（节点序=列序）、删除列（卡片变
  孤儿，按生成语义并入末尾列，看板所见即所得）。
- **cynefin 特化**：五个域固定（不可增删改名），列底部附域间转换编辑器
  （目标域 + 说明 → `complex --> clear : "…"`），转换可删除。

## 架构改动

- `src/lib/util/visualEditor/board.ts`（纯逻辑，13 单测）：`boardColumns`
  派生视图（与生成器 `groupedEmit` 同语义：孤儿并入末列）+
  add/remove/moveColumn、add/remove/moveCard。
- `src/lib/components/visual/BoardEditor.svelte`：看板组件。
- `VisualEditor.svelte`：工具栏按 `canvasView` 分流（画布专属按钮仅画布
  模式渲染），属性对话框抽为 snippet 供全部视图复用，视图区按
  `kindSpec.view` 条件渲染。
