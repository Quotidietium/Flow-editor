# 2.0.94

> 发布日期：2026-08-21
> 主题：整页前端替换补全——覆盖式替换、opaque-origin 桥修复、首个前端替换 e2e

## 变更

- **插件前端改为覆盖式整页替换**：`frontend` 钩子打开的页面现以全屏
  overlay（absolute inset-0 z-40）完全替换编辑器 UI，退出按钮固定右上角
  （不再与 iframe 争抢层叠）；此前为并排块，不符「完全替换前端」语义
- **桥协议 opaque-origin 修复**：data:/blob: 插件前端的 origin 序列化为
  `"null"`，不能作为 postMessage 的 targetOrigin——现回退 `"*"`，内嵌
  data: URL 前端可正常收到 MCP 响应
- **新示例插件** `plugins/examples/frontend-embed.mjs`：自包含（data: URL
  内嵌完整页面）的整页前端替换模板——安装后一键打开，页面经 MCP 桥
  读取/写回编辑器代码
- **新增 e2e**「plugin frontend replaces the UI and drives the editor via
  the bridge」：安装 → 打开前端 → iframe 自动载入编辑器代码 → 修改并
  写回（经桥与输入管道，编辑器真实变化）→ 退出恢复原生 UI——六个扩展点
  至此全部有自动化 e2e 覆盖
