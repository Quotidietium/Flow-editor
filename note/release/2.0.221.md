## 内容

### 循环 159：新建连线后立即输入标签

- 拖出连线落到目标节点后，标签输入框即刻在连线中点打开并聚焦
  ——流程图「是/否」分支、状态图迁移条件这类高频标注，此前必须
  再双击连线才能输入。不需要标签时 Esc 或点空即跳过（无占位、
  不产生多余连线属性）。
- 与新建节点同款（双击加节点/插入骨架落定即开输入），创建类
  手势的交互闭环从此一致：创建 → 输入 → Enter 提交。
- 帮助面板「编辑」组与防漂移断言同步新增条目；既有连线用例
  （visualEditor.spec.ts 选中删除流）适配自动弹框——先 Esc 收框
  再点边中点选中。
