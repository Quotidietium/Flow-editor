> 发布日期：2026-08-21
> 主题：插件 API——输入/导入/导出/主题/整页前端替换/MCP AI 接入的完整插件系统

## 新增

- **插件运行时**（`src/lib/plugins/`）：
  - `types.ts`：插件清单（id/名称/版本/声明式权限）与全部钩子类型
  - `registry.svelte.ts`：源码持久化（localStorage `flowPlugins`）、blob URL
    动态 import 加载、启用/停用/卸载、**钩子错误隔离 + 连续 3 次失败自动停用**、
    主题 CSS 变量注入/还原、运行时实例注册（嵌入宿主/测试）
  - `editorApi.ts`：`window.__FLOW_EDITOR_API__`（getState/setCode/setState/
    getSvg/exportPngDataUrl）——插件与桥共用的命令式 API，全部经状态网关
  - `bridge.ts`：**MCP（Model Context Protocol）JSON-RPC 2.0 over
    postMessage 服务器**（频道 `flow-editor`）：`initialize`/`tools/list`/
    `tools/call`/`ping`；工具集 `get_code`/`set_code`/`get_state`/`set_state`/
    `render_svg`/`export(svg|png-dataurl|code)`——外部 stdio MCP 客户端转发
    该协议即可让 AI 完全驱动编辑器
- **六类扩展点**：
  1. `inputTransform`——输入管道（清洗/格式转换），链式执行，触发于文件打开/
     桥接写入/URL 载入（按来源可区分）
  2. `import`——自定义文件格式优先接管「打开」（按扩展名分派）
  3. `export`——自定义导出格式追加进「导出 ▾」菜单（文本或二进制 Blob，
     私有格式/MC 插件等任意目标）
  4. `theme`——CSS 变量级配色修改，启停即时生效/还原
  5. `frontend`——**整页前端替换**：插件提供 URL → 沙箱 iframe 全屏渲染，
     通过桥协议完全驱动编辑器，随时退出
  6. `ai:mcp`——见 bridge；插件前端示例页面演示了完整读写回路
- **插件管理器**（导航栏「插件」按钮）：本地 .mjs 安装、启用/停用/卸载、
  权限展示、插件前端入口
- **示例插件**（`plugins/examples/`）：输入清洗（换行归一/PlantUML 剥壳）、
  MC 函数导出（.mcfunction tellraw）、紫色主题、整页前端替换 HTML（桥驱动）
- **API 文档**：`note/plugin-api.md`（全部钩子签名、ctx、安全模型）

## 安全模型

插件由用户从本地主动安装（VS Code 扩展同信任级），离线应用不拉取远程脚本；
权限清单在管理器明示；钩子隔离 + 三振停用；存储按插件 id 命名空间隔离；
iframe 前端运行于沙箱并仅能经桥访问编辑器。
