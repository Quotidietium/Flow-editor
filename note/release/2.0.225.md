## 内容

### 循环 163：分享对话框链接长度读数与截断预警

- pako 哈希把整图塞进 URL，超大图的分享链接在部分聊天/邮件工具
  里会被截断——接收者点开即坏链，此前发送方毫无知觉。只读链接
  行下现在给出「链接长度 N 字符」读数；过 8000 字符转琥珀色并附
  替代建议（改用导出 PNG/SVG 或 .mmd 文件分享）。
- 与 CopyInput 同口径：对话框每次打开重挂载时取当下 hash（脚本
  顶层常量会拿到过期链接——既有注释教训）。`{@const}` 不是 div 的
  合法直接子级（svelte-check 拦下），改为脚本函数内联调用。
