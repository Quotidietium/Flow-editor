## 内容

### 循环 125：围栏粘贴剥离（双端）

- 从文档/LLM 对话复制 mermaid 代码的最高频形态是整段
  ` ```mermaid … ``` ` 围栏——粘进代码编辑器连围栏一起算语法必然
  报错。现在**粘贴即剥离**：整段恰是一个围栏时原位替换为裸代码并
  toast 告知；替换可 Ctrl+Z 撤销，状态流/预览照常接管。
- **只剥离裸围栏或标注 mermaid/mmd 的围栏**：标注其它语言（如
  ` ```python `）显然不是 mermaid，原样放行交给语法错误横幅。
- 与文件打开路径既有行为对齐：`.md` 打开本就提取首个 mermaid 围栏
  （`fileIO.parseOpenedFile`），本循环补齐粘贴侧缺口。
- 实现：`stripCodeFence.ts` 纯函数（前导空白可容、CRLF 归一 LF、
  「文中围栏」不误剥）；桌面 Monaco 挂 `onDidPaste` 原位
  `executeEdits`；移动端 CodeMirror 在 updateListener 识别
  `input.paste` 事务标注后原位 dispatch 替换。
