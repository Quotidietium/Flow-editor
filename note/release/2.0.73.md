# 2.0.73

> 发布日期：2026-08-20
> 主题：性能优化第三循环（画布拖拽布局抖动消除 / 两项候选测量否决）
> 分支：`feat/perf-optimization`（续 2.0.71/2.0.72 的优化轮次）

## 新增

- **可视化画布拖拽消除布局抖动**：`svgPoint` 不再在每次 pointermove 读
  `getBoundingClientRect`（与拖拽属性写入交错造成每次移动一次强制同步布局）——
  改为**手势级缓存**（画布滚动失效、pointerup 清除），40 次移动拖拽的布局读取
  **42 → 1**；snap 吸附值未变化时跳过赋值，消除无效响应式失效
- **防回归资产**：`normalizeLabeledLinks` 差分测试（2000 行随机语料 + 手工边角，
  钉死顺序替换语义——单遍重写方案因重叠区域语义分歧被差分捕获并否决）；
  `render-placement.bench.ts`（mock mermaid 的放置路径基准）

## 测量否决（记录在案，零行为变更）

- renderView 作用域查询：0.0716→0.0720ms（噪声内），改动回退
- normalizeLabeledLinks 单遍合并：差分发现 `== … -. t .-> …` 重叠场景输出分歧，
  红线不可接受，回退（Round 6 风险评估由此获得具体反例）

## 测试

- 新增研究脚本 `benchmark/studies/visual-drag.mjs`（pako URL 构造 300 边图、
  可视区节点定位、拖拽插桩计数与帧率采样）
- 全量 e2e：42 通过 / 3 预存 skip / 0 失败（含 noNetwork 零外联守卫）
- 单元测试 125 通过（15 个本机预存失败与基线一致）；svelte-check 0/0；
  eslint / prettier 通过
