# 2.0.86

> 发布日期：2026-08-20
> 主题：可视化编辑界面切换回 Mermaid 显示方式——分屏实时渲染

## 新增

- **Visual 标签分屏**：编辑界面在交互画布旁恢复 Mermaid 的真实显示——右侧
  新增「Mermaid 实时渲染」窗格（`VisualPreview.svelte`），复用生产渲染管线
  `renderAndPlaceDiagram`，主题/手绘模式/全部 31 类图与预览面板渲染完全一致
- 实时同步：画布上的任何编辑（建节点、改标签、拖拽坐标类图……）经 250ms
  防抖后立即在渲染窗格看到 Mermaid 的真实效果，无需切回预览标签
- 容错：编辑中间态代码非法时保留上一次渲染并降透明度提示，恢复合法后自动刷新
- 工具栏「预览」开关（记忆偏好 `visualEditorPreview`，默认开启）；移动端单栏
- 渲染串行化（Promise 链）+ 组件卸载取消待渲染：快速 Visual↔预览切换零多余渲染

## 设计说明

自绘画布（VNode/VEdge 盒子）无法呈现各类图的 Mermaid 真实形态（饼图/甘特图
等尤甚）；而直接在 Mermaid 渲染结果上编辑不可行——Mermaid 布局不感知用户
坐标，拖动后连线不会重排。分屏方案两者兼得：编辑用画布，显示用 Mermaid。
详见 [visual-editor.md](../visual-editor.md) §8 与
[visual-editor-ux-design.md](../visual-editor-ux-design.md) 方向修正节。
