## 审计结论与修复

**Editor 桌面/移动切换边界**：`{#if isMobile}` 分发两编辑器共享同一
`onUpdate` 网关闭包；击键经状态网关先于切换落库，重挂载从
`validatedState` 重建——切换无状态丢失路径（设计正确）。compare 栏在
移动端正确隐藏（`hidden sm:flex`）。新增 e2e 钉死全边界：Monaco 输入 →
跨 640px 视口边界 → CodeMirror 挂载且携带相同代码 → 移动端继续编辑经
网关渲染

**长会话 toast 治理（修复）**：`<Toaster />` 无上限——23 个 notify 调用
点在长会话高频操作下（连续载入/插件错误/历史导入）可无限堆叠 DOM。
修复：`visibleToasts={4}`（sonner 语义：超出即回收最旧，队列不积压）
