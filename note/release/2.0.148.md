# 2.0.148

> 发布日期：2026-08-25｜分支：`develop`
> 主题：**WEB UI 舒适度优化循环 35–38**——移动端历史返回、配置模板差异
> 预览、预览背景四档切换、移动端可视化入口自动翻页。

## 内容

### 循环 35：移动端历史全屏面板返回按钮

- 移动端历史面板全屏接管工作区时，导航栏开关对新用户不够可见——面板
  右上角补显式「返回」按钮，关闭面板回到编辑布局（390px 实证）。

### 循环 36：配置模板差异预览

- 模板菜单底部新增预览区：悬停/聚焦任一模板即列出「将修改的叶子键」
  （点路径: 旧值 → 新值；未设置标注、超长截断、仅列实际变化项、全部
  已生效时明示无变化）——一键合并前不再盲猜会改什么。
- 纯函数 `diffConfigLeaves` 与深合并同语义（对象递归出点路径、数组/
  标量整体覆盖比较），保留「最后悬停」避免菜单内移动时预览闪烁。

### 循环 37：预览背景四档切换

- PanZoomToolbar 新增循环钮：网格点 → 棋盘格（透明检查）→ 纯白 →
  纯黑。棋盘格是设计工具通用的透明底示意，核对透明 PNG/SVG 导出；
  纯白/纯黑核对文档嵌图与暗色幻灯片效果。
- localStorage 持久化 + 手改白名单兜底（非法值回落网格点）；编辑页与
  /view 全屏页共用同一档位。/view 保持素净默认（grid 档不上点阵），
  但用户显式选档后处处生效——否则该页切换钮形同虚设。

### 循环 38：移动端开可视化自动翻到画布半屏

- 移动滑屏布局（代码半屏 | 预览半屏）下可视化画布挂在预览半屏；用户
  在代码半屏点「可视化」开关此前「点了没反应」（画布在屏外）。现跟随
  visualMode 上升沿自动翻页（`untrack` 摘掉 isMobile/isViewMode 依赖），
  用户随后手动翻回代码半屏不被拽回。
