# 2.0.146

> 发布日期：2026-08-25｜分支：`develop`
> 主题：**WEB UI 舒适度优化循环 27–30**——编辑器状态栏、导出倍数、
> 恢复反馈、错误来源分流。

## 内容

### 循环 27：编辑器状态栏

- 编辑器底部显示**光标行列 + 总行数**（语法错误行号的对照锚点），
  Monaco `onDidChangeCursorPosition` / CodeMirror `updateListener` 双端
  同构；与「定位到错误行」联动（定位后状态行同步到错误行）。

### 循环 28：光栅导出倍数 1x / 2x / 3x

- `exportCanvasSize` 新增 `scale` 参数：结果整体放大 + 单边 10000 夹取 +
  非法倍数回退 1x；操作卡片倍数 chips（**会话级**——持久化一个被遗忘
  的高倍数会在下次会话产出意料之外的巨型文件）。
- e2e 像素级判别：解析 PNG IHDR，断言 3x 双边恰为 1x 三倍（±1 取整）。

### 循环 29：恢复历史条目 toast 反馈

- 恢复是静默的全量替换：补「已恢复 ×」toast——对比模式/窄屏下用户
  不一定立刻察觉画布已换。

### 循环 30：错误条按来源分流

- `ValidatedState.errorSource`（code / config）：配置 JSON 改坏与图表
  语法改坏不再混为一句「语法错误」——错误条分别显示**配置 JSON 错误**
  与**图表语法错误**。
