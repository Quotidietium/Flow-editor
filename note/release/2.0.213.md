## 内容

### 循环 151：视图复位捷径

- **预览区双击复位**：预览画布（/edit 预览、/view、embed 同组件）
  双击空白即回归基准缩放（0.875，与工具栏「重置视图」/键盘 0 同一
  语义）——draw.io 式捷径，放大检视细节后免找按钮。预览 svg 无其他
  双击占用（可视化画布的「双击加节点」在另一组件，互不干扰）。
- **可视化画布缩放读数可点击**：画布工具栏的 `%` 读数（循环 122 系列
  起随缩放更新）变为按钮，点击复位视图（同 Ctrl+H）；画布帮助「复位
  视图」条目键位同步为 `Ctrl + H / 点击缩放读数`。
- 主菜单「快捷键与操作」收录「双击预览 = 复位预览缩放」。
