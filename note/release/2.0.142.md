# 2.0.142

> 发布日期：2026-08-25｜分支：`develop`
> 主题：**WEB UI 舒适度优化循环 6–14**——编辑器与历史/导出体验细化九连，
> 含「我的模板」（用户自定义配置预设）落地。

## 内容

### 循环 6：语法错误条「定位到错误行」

- 错误条右侧新增定位按钮：把首个错误标记行滚到视口中央、放置光标并
  聚焦编辑器（`DesktopEditor.revealPosition`，仅桌面端有标记时渲染）。

### 循环 7：示例图表搜索过滤

- 33 个示例类目顶部搜索框：同时匹配类目中文名 / 英文原名 / 示例标题，
  大小写不敏感；无匹配提示、Esc 恢复。

### 循环 8：导出菜单「复制 SVG 源码」

- 与 SVG 下载同源（克隆 + xlink 命名空间的干净 SVG）一键复制到剪贴板，
  粘贴到文档/设计工具免下载中转。

### 循环 9：代码模式「插入片段」菜单

- 编辑器头部新增插入菜单（代码模式）：节点 / 连线 / 带标签连线 / 注释行 /
  子图骨架 / 时序参与者 / 时序注释 7 个骨架，**光标处插入不替换全文**，
  与「示例图表」整图替换互补；Monaco executeEdits / CodeMirror
  replaceSelection 双端。

### 循环 10：PNG / WebP 透明背景导出

- 操作卡片新增「透明背景」选项（持久化 `pngTransparentBg`）：勾选后画布
  不填底色、SVG 不带 backgroundColor；JPEG 无透明通道、PDF 按文档惯例，
  二者强制不透明。

### 循环 11：PanZoom 缩放百分比读数

- 缩小/放大按钮之间显示当前缩放百分比（种子值取实例 `currentZoom()`，
  `onZoomLevelChange` 回调随缩放/平移/复位/恢复更新，`destroy` 清理）；
  重置视图回归 88% 基准。

### 循环 12：编辑器字号调节

- 头部字号菜单 12/14/16/18/20 五档（双端，构造即生效），偏好
  `editorFontSize` 跨会话保持。

### 循环 13：时间线条目一键收藏到「已保存」

- 时间线 30 条先进先出易冲掉重要版本：条目行新增收藏按钮，
  `addManualEntry` 保留原名称，去重提示与手动保存一致。

### 循环 14：自定义配置模板（「我的模板」）

- 模板菜单新增「我的模板」区：保存当前配置为模板（同名覆盖、可删除，
  localStorage `flowUserConfigPresets` 持久化），应用语义与内置模板一致
  （深合并）；加载期白名单校验（id/label/对象/单条 10KB/共 20 条上限），
  手改的非法条目静默丢弃。
