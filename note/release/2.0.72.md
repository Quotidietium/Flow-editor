# 2.0.72

> 发布日期：2026-08-20
> 主题：性能优化第二循环（导出延迟 / 编辑器标记去重）
> 分支：`feat/perf-optimization`（续 2.0.71 的六个优化轮次）

## 新增

- **导出提速 ~14x**：PNG 导出 / 复制图像前的固定 **1000ms sleep** 替换为事件驱动等待
  （`waitForRender` + rAF 轮询干净 SVG，5s 截止兜底）——click→download 中位
  **1037ms → 75ms**，导出字节不变；慢图上（autoSync 防抖降级）比固定等待更可靠
- **编辑器标记去重**：DesktopEditor 不再在每次状态发布上无条件
  `monaco.editor.setModelMarkers`（相同标记也会重建装饰）——画布拖拽期间标记应用
  **59 次 → 0 次**，打字时标记照常更新
