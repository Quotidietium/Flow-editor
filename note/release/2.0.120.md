## 表格编辑器（SheetEditor）

覆盖 pie / packet / radar / xychart / venn / eventmodeling / railroad 共 7 类。
这些图本质是「类型化记录的扁平列表」，表格即心智模型：一行 = 一条记录，
一列 = 一个字段，即改即存（blur/Enter 经 `commit()` 发布一次 undo 快照）。

- **分区表**：radar（维度轴 + 曲线）、venn（集合 + 交集）、xychart
  （横轴 / 纵轴 / 数据系列）按角色分区，每区独立添加按钮与行计数。
- **字段控件**：文本输入（切片名/数值/位区间/表达式…）+ 下拉选择
  （eventmodeling 四类型、xychart 柱状/折线、railroad `=`/`<-` 运算符）。
- **行操作**：添加（自动聚焦新行）、删除、上移/下移（交换节点序——
  饼图切片等顺序即代码顺序）。
- 配置驱动：`sheet.ts` 的 `SHEET_CONFIG` 声明各区 roles/字段/新行角色，
  纯函数 addRow/removeRow/moveRow/sheetRows 可单测。
