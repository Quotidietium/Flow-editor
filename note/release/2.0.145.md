> 主题：**WEB UI 舒适度优化循环 23–26**——Monaco 小地图、示例最近使用、
> /view 只读页增强、示例按钮关键字提示。

## 内容

### 循环 23：Monaco 小地图开关

- 编辑器头部新增小地图切换（仅桌面端，移动端隐藏），偏好
  `editorMinimap` 跨会话保持；构造参数与 effect 双路径应用
  （沿用换行/字号的订阅教训）。

### 循环 24：示例图表「最近使用」

- 点用的图类目记入 `presetRecent`（去重置顶、上限 6 条、跨会话保持、
  加载期白名单校验），示例卡片顶部「最近使用」行一键直达。

### 循环 25：/view 只读页增强

- 裸页只有手势：补 PanZoom 工具栏（缩放读数/复位/缩放按钮）与
  「在编辑器中打开」回链（客户端拼当前 hash）——分享链接接收者
  一键回到编辑态。

### 循环 26：示例类目按钮悬停显示 Mermaid 关键字

- 类目按钮 `title` 展示该图类型的 Mermaid 头关键字
  （Flowchart / Sequence / …），学语法零成本。
