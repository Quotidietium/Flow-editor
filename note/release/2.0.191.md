## 内容

### 循环 129：跟随系统明暗三态

- 主菜单「深色模式」行升级为**「外观」三段选择**（浅色 / 跟随系统 /
  深色）：此前两态 Switch 一旦点击就**永远回不到「跟随系统」**——
  而 mode-watcher 的默认偏好恰是 system（新用户的初始状态）。现可
  一键回到跟随；原始偏好高亮 + aria-pressed，持久化沿用
  mode-watcher 的 `mode-watcher-mode` 键。
- **mermaid 配置 theme 联动零改动继承**：`mode.current` 是派生值
  （system 态实时响应 `prefers-color-scheme`），`+layout` 既有
  `toggleDarkTheme` 联动在系统切换时同样触发——默认系主题（default/
  dark）跟随系统翻转，自定义主题（forest 等）不受影响（e2e 实证）。
- 导航栏明暗直达钮语义不变：任意态下点击 = 显式切到相反主题
  （system 态下即退出跟随）。
- 旧「整行点击切换 + Switch」交互移除：原 a11y 问题（整行可点假象）
  随原生 button 三段钮结构性消除，`mainMenuDarkRow.spec` 重写为
  三态语义。
