| ---- | ------------------------------------------ | --------------------------------------------------------------------------------------------------------- |

## 变更明细

- `src/lib/util/errorHandling.ts`：算法重写（语义逐字节一致，差分测试守护）；新增 `errorHandling.test.ts`（16 用例，含旧实现参照差分）
- `src/lib/util/serde.ts`：deflate level 6（任何级别经同一 inflate 解压，新旧 URL 双向兼容；URL 长度 +0.7%~2.1%）
- `src/lib/util/state.svelte.ts`：`validatedStateOf` 惰性 serialized getter；`updateHash` 无参防抖（flush 读最新态）；view 链接同拍防抖；`urls.new` 常量预计算；`parseAndCache` 代码级 parse 缓存（含完整错误/标记复用与并发防护）
- `src/lib/util/mermaid.ts`：`getSampleDiagrams` 异步化（动态导入 `@mermaid-js/examples`）
- `src/lib/components/Preset.svelte`：示例异步填充 + `diagramOrder` 派生化（修复过渡期 undefined 索引）
- `src/lib/util/visualEditor/model.ts`：扫描器/边 ID/布局优化（金样测试守护）
- 新增测试：`errorHandling.test.ts`（16）、`state.cache.test.ts`（3）、`model.golden.test.ts`（5）；`benchmark/` 6 个基准文件 + 研究脚本
- 依赖：移除 `plausible-tracker`（2.0.69 起零引用）

## 测试适配

- serde 内联快照随压缩级别更新（round-trip 断言不变）

## 验证

- 单元测试：123 通过（新增 24）；15 个本机预存 localStorage 失败与 2.0.67 基线一致（CI Linux 通过）
- 全量 e2e：**42 通过 / 3 预存 skip / 0 失败**（含 noNetwork 零外联守卫，与 2.0.70 基线一致）
- svelte-check 0 错误 0 警告；eslint / prettier（改动文件）通过
- 生产构建成功，immutable 总体积不变（+2.4KB 垫片）

## 红线决策记录（不改变用户体验）

- localStorage 写入保持同步（防抖会引入「输入即关标签页丢字」的耐久性变化）
- Monaco/CodeMirror 不懒加载（编辑器出现时机属体验红线）
- `normalizeLabeledLinks` 不合并正则（边角语义风险 > 收益）
- ZenUML 注册保持现状（解析回归风险，收益不明确）
