## 内容

### 循环 148：键盘缩放 +/-/0/F

- 预览区与 /view 只读页（含 embed）补齐键盘缩放路径：
  **+**（或 =）放大、**-**（或 _）缩小、**0** 重置视图、**F** 适应
  窗口——与工具栏四钮同一 `PanZoomState` 语义，读数同步更新。
- 实现在共享的 `PanZoomToolbar`（`svelte:window` 监听），三个挂载
  点（/edit 预览、/view、embed）同享；**输入态让路**：编辑器/
  输入框/contentEditable 聚焦时不劫持，修饰键组合（Ctrl++ 浏览器
  页面缩放等）不拦。
- 四个工具钮 title 标注键位（「放大（+）」等，可发现性）；主菜单
  「快捷键与操作」收录 `+ / - / 0 / F` 一行。
- 与可视化画布键位零冲突（画布只绑 Ctrl 组合/F2/方向键/Delete）。
