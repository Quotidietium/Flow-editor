## 新增

- **插件类型声明** `plugins/flow-plugin.d.ts`：插件作者在 .mjs 顶部加一行
  `@satisfies {import('../plugins/flow-plugin.d.ts').FlowPlugin}` 即获得
  全部钩子/清单/上下文的 IDE 类型提示（无需构建步骤）
- **AI 工作流示例插件** `plugins/examples/ai-prompt-exporter.mjs`：导出
  「图表源码 + 指令 + 编辑器 MCP 工具协议」的 LLM 提示词文件（.md）——
  演示插件与任意 AI 客户端的桥接模式（也可在 activate 里直接 fetch 自选
  AI 端点并用 ctx.setCode 写回）
- **文档补全**（`note/plugin-api.md`）：「类型提示」用法一节；MCP 一节新增
  「插件作为 AI 客户端」模式说明（主动 fetch + setCode 回写 / 提示词导出
  两种路径）
