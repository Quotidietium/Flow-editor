## 审计结论与修复

**compare 模式 viewPane 双渲染**：两处 `{@render viewPane()}` 位于互斥
分支（纯预览态 vs 可视化+对比栏），同一时刻仅一个 View 实例；模式切换时
旧实例销毁触发 `PanZoomState.destroy`，页面级单实例 state 重挂载时经
`updateElement` 重建——生命周期正确，无监听器累积、无状态串扰

**新 localStorage 键校验一致性**：

- `visualEditorSizes`：已有白名单但**缺上限**——修复：w≤900/h≤600
  （与缩放手势内联上限一致）
- `visualEditorLayout`（sanitizePositions）：只查有限数**缺范围**——
  修复：|x|,|y|≤10,000（画布世界 3000×2000 + 余量）。此前手改
  localStorage 存 `1e300` 会把节点几何放大到天文数字，污染全部几何
  计算与 SVG 属性
- `visualEditorEdgeStyle`：三元白名单（straight/curved/else）✓ 无需改
- 新增 `sanitizePositions` 范围拒绝回归单测（1e300 剔除、边界 10,000
  保留）
