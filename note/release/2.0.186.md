## 内容

### 循环 124：实时预览暂停

- 预览工具栏新增**暂停开关**（编辑页专属；/view 只读页与 embed 不
  出现）。大图每键击渲染可达数百毫秒，连改时被渲染卡住——暂停后
  编辑畅写，画面持有不动。
- 暂停期间如有未渲染改动，画面角落显示**陈旧指示**（「画面为改动
  前的版本」）+ **立即渲染**一键补渲——用户不必回忆工具栏里还有个
  开关。指示牌位于右下版本/主题工具栏上方（bottom-14），否则按钮
  被其拦截点击（e2e 实证）。
- **会话级开关，不持久化**：被遗忘的暂停会让新会话「改了没反应」
  假死——刷新即回实时（与导出倍数同为会话级先例）。
- **导出前自动恢复**：导出的必须是当前代码的画面而非暂停前的陈旧
  图，`runExport` 先解除暂停再走 waitForCleanSvg（补渲染经 View
  的 effect 队列落地）。
- 实现：`previewPause.svelte.ts` 响应式单例（$state，会话级）；
  View 渲染管线在「无变化短路」之后、节流判定之前检查暂停（陈旧
  判定天然复用「最后渲染值」）；暂停开关的翻转在 View effect 内
  读取依赖，解除即补渲染；自适应节流（>150ms 降频）在其后不受影响。
