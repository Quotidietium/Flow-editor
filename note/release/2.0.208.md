## 内容

### 循环 146：差异行键盘可达

- 差异行补齐键盘路径：行可聚焦（`tabindex="0"` + `role="button"`），
  **Enter/Space 复制该行**，焦点态高亮（focus-visible 环 + 底色）——
  循环 145 的悬停复制钮本就键盘可达（focus-visible 常显），行级
  聚焦后整行热区更大，两者并存。
- 候选核验作废：①「/view SVG 透明背景」已在循环 114 实现并被
  viewPage.spec 覆盖；②「我的示例」行导航已在循环 142 覆盖（网格
  容器全按钮统一参与）。

### 配套：DEV_PORT 环境变量（本机环境漂移绕开）

- 本机 Windows 动态保留端口范围（Hyper-V/WSL 触发，`netsh interface
ipv4 show excludedportrange`）漂移到 **2911–3010**，dev server
  `listen EACCES: 3000` 无法启动、全量 e2e 全挂。
- `vite.config.js` 与 `playwright.config.ts` 的端口支持
  `DEV_PORT` 环境变量覆盖（默认 3000 行为不变，CI/其他环境无感）；
  本机以 `DEV_PORT=3200` 跑测试绕开保留区。
