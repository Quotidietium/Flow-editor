# 2.0.76

> 发布日期：2026-08-20
> 主题：可视化编辑器位置记忆——切换/刷新不再重排（真正的所见即所得）

## 新增

- **位置记忆**：Mermaid 源码不携带坐标，此前每次切入 Visual 标签都会全量自动布局，
  用户刚放好的节点在每次切换后明显跳回布局槽位。现在画布按**节点 id 记忆位置**
  （模块内存 + localStorage `visualEditorLayout`），叠加在自动布局之上
  （`model.applyPositions` 纯函数）：
  - 切换 Visual↔预览任意次、刷新页面、在 Code 标签小幅编辑后，节点位置全部稳定
  - 新增节点无记忆时落在自动布局槽位；「整理布局」重排后新位置立即成为记忆；
    「清空」/删除同步收缩记忆表
  - 位置不写入 Mermaid 代码（无机器注释污染分享链接）；跨设备首次打开仍会
    自动布局一次（取舍记录见 visual-editor.md §6）

## 测试

- 新增 e2e「keeps node positions across mode switches and reloads」：拖动节点 →
  切出/切入 Visual → 刷新页面，bounding box 保持不变（±1px 容差，覆盖选中描边宽度差）
- 新增 `applyPositions` 单测（覆盖叠加/空表/陈旧 id 语义）
- 全量 e2e：42 通过 / 3 预存 skip / 0 失败；单测 147 通过（15 个本机预存失败与基线
  一致）；svelte-check 0/0；eslint / prettier 通过
