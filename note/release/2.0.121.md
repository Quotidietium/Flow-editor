## 大纲编辑器（OutlineEditor）

覆盖 mindmap / treeview / treemap / ishikawa / swimlane 共 5 类。层级用
缩进表达、一行一个节点——经典 outliner 心智模型，取代「自由画布上拖
位置 + 连线表层级」的别扭交互。

- **键盘流**：Enter = 新建同级（自动聚焦新行直接输入）、Tab = 缩进为
  上一同级的子级、Shift+Tab = 取消缩进（回到父级的下一个同级）。
  结构键与未提交标签合并为**同一次 undo 快照**（先冲刷标签再做结构
  变更，避免撤销粒度错乱）。
- **行内操作**：添加子级、上移/下移（同级内排序）、缩进/反缩进、删除。
- **删除语义**：子级提升到被删行的位置（outliner 标准行为；删根节点时
  子级原位变根），不会级联误删整棵子树。
- **类型特化**：treemap 行附「数值」输入（叶子值）；mindmap 行附形状
  下拉（矩形/圆角/胶囊/菱形）。
- 纯逻辑 `outline.ts`：`outlineRows`（迭代式 DFS 扁平化，环 stranded
  节点降级为合成根，绝不出现不可编辑的节点）+ addChild /
  addSiblingAfter / indentRow / outdentRow / removeRow / moveRow。
