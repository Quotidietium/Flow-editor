# 2.0.131

> 发布日期：2026-08-23
> 主题：MC 进度设计器持续优化循环（两轮自查，11 项缺陷修复 + 9 种新触发器 + 3 项 UX 改进 + 真实浏览器验收）

## 内容

### 缺陷修复（循环 1 自查发现）

- **插件前端全屏时导航栏拦截点击**（产品级缺陷，影响所有带前端的插件）：
  导航栏是根 flex 容器的 flex item，`z-50` 无需定位上下文即压在插件前端
  覆盖层（z-40）之上，前端页面顶部约 64px 条带全部不可点。修复：前端激活
  时卸载 Navbar（不是调 z-index——层级由 flex 顺序决定，卸载最干净）。
- **join 的 firstOnly 配置键不一致**：config.yml 写 `firstOnly`，生成的
  Java 却读 `first-only`——用户关闭「仅首次加入」会静默失效（永远拿默认
  true）。已统一为 `firstOnly` 并加单测钉住。
- **reach_height 负 Y 被校验误杀**：min 默认 0 兜底导致 below 模式
  （如下潜至 Y=-60）无法通过校验；min 现仅在显式声明时生效。
- **Java 枚举名冲突**：`1abc` 与 `a_1abc` 规范化后都映射枚举 `A_1ABC`，
  生成的 Java 无法编译；analyze 新增枚举名查重（含大满贯 completionist
  id 的后缀避让也纳入枚举名空间）。
- **advancement_done 无法指向本插件进度**：监听器里该触发检查在
  `NAMESPACE.equals` 分支的 return 之后，永远不会执行；已前移并加生成
  代码顺序断言。
- **编译中可连点**：编译按钮加 loading 禁用态。
- **前端 confirm 被沙箱静默吞**：sandbox 补 `allow-modals`。
- **长编译被前端桥 5s 超时打断**：桥调用超时参数化，mc_build 用 90s。
- 非法分量（多根/纯环/id 冲突）的节点此前不进前端模型，面板无法选中
  修复；现保留（tab=null），左栏显示「⚠ 结构异常」分组，可改挂父级修复。

### 新增校验与告警

保留命名空间（minecraft/bukkit/mojang/paper/spigot）报错；图标/材质/
生物/统计项 ID 格式告警；命名空间与插件名的静默规范化现给出警告而非
无感改写；版本号格式建议（作为 jar 文件名）。

### 9 种新触发器（21 → 30 种，全部经真实 paper-api javac 编译验证）

剪羊毛（PlayerShearEntityEvent）、骑乘生物（EntityMountEvent）、进入
传送门（EntityPortalEnterEvent）、累计受伤（EntityDamageEvent）、弹射物
命中（ProjectileHitEvent，命中实体 + shooter 为玩家）、开始滑翔
（EntityToggleGlideEvent）、开始游泳（EntityToggleSwimEvent）、装桶
（PlayerBucketFillEvent）、获得经验（PlayerExpChangeEvent，负变动不计）。

### UX 改进

- 触发器下拉按六类 optgroup 分组（日常 / 收集与建造 / 战斗与冒险 /
  探索与世界 / 技能与进度 / 手动）——30 项平铺已不可寻。
- 栏根节点的属性表单精简为「名称 + id + 说明」——触发器/父级/框架等对
  栏根本无意义，此前展示全部控件造成困惑。
- 删除守卫区分栏根（引导去栏设置）与孤儿节点。

### 后续循环（6–7）补充修复

- **栏根节点表单不可达**（循环 6）：树渲染跳过根节点（根即栏头），点栏头
  进入的是栏设置——循环 1 做的「栏根节点改名/改 id」表单没有任何入口。
  现并入栏设置顶部（名称 + id + 适用性说明）。
- 新增警告：成就名称为空（游戏里显示空白）、不同 id 同名成就（玩家无法
  区分）、背景纹理非 `minecraft:textures/…png` 格式（紫黑棋盘风险）。
- **写回静默覆盖外部修改**（循环 7，数据安全）：面板打开期间主界面画布
  或分享链接的改动会被「写回编辑器」直接覆盖丢失；现写回前与上次同步
  基线比对，弹确认让用户选择「面板覆盖」或「重读外部版本」。
- 事故拦截记录：冲突提示文案里的 `\n` 在外层模板字符串中被求值为真实
  换行、杀死整个内嵌脚本——被循环 1 加的「内嵌脚本语法探针」单测当场
  抓住（该探针正是为此类回归建的防线）。
