# 2.0.81

> 发布日期：2026-08-20
> 主题：稳定性审计第 7 轮——三个已登记候选逐项核查并修复

## 修复

- **URL 超长退化**：极端大图的 hash 超出浏览器 URL 上限时 replaceState 抛异常，
  原先每次击键都从防抖定时器重抛未捕获错误——现在容错并继续编辑/发布
- **多标签丢更新**：历史保存/删除原先整替写本标签的陈旧内存副本，静默丢弃
  其他标签页自页面加载以来的手动保存——写前重读最新持久值合并（残余竞窗缩至
  毫秒级）；codeStore 的 last-writer-wins 写入完整合法快照，属预期语义
- **位置表写入护栏**：病态大图（千节点）的位置表超过 100KB 跳过 localStorage
  入库（本会话内存仍生效），常规图写频（每次已提交手势一次）确认可接受

## 测试

- 新增 2 个单测（URL 同步容错双周期、跨标签保存合并/删除保留）；全量 e2e
  42 通过 / 3 预存 skip / 0 失败；单测 172 通过（15 个本机预存失败与基线一致）；
  svelte-check 0/0
