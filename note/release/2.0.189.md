## 内容

### 循环 127：历史版本对比

- 历史面板每个条目新增**「与当前对比」**按钮（与「恢复此版本」
  并排）：对话框内行级对比「该版本 → 当前编辑器」，`+`/`−`/上下文
  着色行 + **增/删计数**统计——「这张图我改了什么」不再靠肉眼逐行找。
- **零依赖行级 LCS diff**（`util/lineDiff.ts`）：常规图表量级 DP
  可控；单侧超 2000 行降级为整段替换（不伪报逐行差异）；空串视为
  零行（「空 → 有内容」= 纯新增）。对话框渲染上限 400 行 + 截断
  提示（统计仍为全量）。
- 仅对比**图表代码**：配置 JSON 的差异预览在配置模板菜单另有其责，
  不重复。
- 语义说明：恢复条目、在新标签打开、收藏等既有能力不变；对比为
  纯只读视图。
