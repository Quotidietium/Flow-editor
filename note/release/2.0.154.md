# 2.0.154

> 发布日期：2026-08-25｜分支：`develop`
> 主题：**WEB UI 舒适度优化循环 59–62**——Outline 行过滤、时间线清空
> 文案分流、括号配对着色、/view 页复制链接。

## 内容

### 循环 59：Outline 行过滤

- 深 mindmap/大鱼骨图定位节点全靠滚屏——行区上方补过滤框：名称+数
  值匹配；命中行连同**全部祖先保持可见**（树上下文不断链，只隐去无
  关分支）；命中计数、Esc 清空、零匹配提示；只过滤显示不动数据。
  至此 Board/Sequence/Outline 三类长列表编辑器过滤齐。

### 循环 60：时间线清空确认文案按标签页分流

- 清空按钮两页可用且作用于当前页存储（clearActive），但确认文案两页
  都写「确定清空全部已保存项目？」——时间线页点清空被误导。现按页
  分流（时间线全部条目/全部已保存项目），按钮 title 同步。

### 循环 61：Monaco 括号配对着色 + 缩进/括号参考线

- 配置 JSON 嵌套一深就靠数括号——editorOptions 开启
  `bracketPairColorization` 与 `guides`（bracketPairs+indentation），
  纯视觉辅助不改文档。

### 循环 62：/view 页复制链接

- 观看者再分享免手选地址栏长串 pako——一键复制当前 URL 入剪贴板。
  /view 页工具集齐：在编辑器中打开 / 下载 SVG / 下载 PNG / 复制链接 /
  缩放与背景。
