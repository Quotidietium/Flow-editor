### 循环 149：差异跳转（上一处/下一处 + 计数）

- 版本对比对话框新增差异导航：**‹ / ›** 循环跳转 + `当前/总数` 计数，
  目标簇滚动居中——循环 147 折叠后差异簇在长文里相距甚远，纯滚动
  寻找费时。
- 差异簇锚点按行级 diff 聚类：相邻 diff 行间隔 ≥10 行相同行
  （= 2×上下文 3 + 最小折叠 4，`FOLD_CONTEXT`/`FOLD_MIN` 常量在
  `lineDiff.ts` 导出共享）才算两「处」——与展示层折叠阈值同源，
  展示上相邻无分隔的簇不拆。
- 游标初始未定位（显示 0/N），首个「下一处」落在第一处；到达末端
  后循环回卷；切换对比对象/对调方向/重开对话框与折叠展开态一并复位。
- 无差异（0 增 0 删）时导航整组不出现。
