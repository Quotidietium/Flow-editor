## 内容

### 循环 160：代码区 Ctrl+滚轮调编辑器字号

- 桌面编辑器（代码页/配置页同在）悬停时 Ctrl+滚轮直接调字号，
  与 VS Code 肌肉记忆一致——此前只能挪手去开字号菜单。
- 滚轮写回共享偏好单例（editorFontSize）：字号菜单读数、跨会话
  持久化、12–20 夹取全自动跟随，单一事实源不分裂。滚轮步进 1
  （比菜单 ±2 细）；无 Ctrl 的滚轮照常滚动编辑器，不劫持。
- capture 相监听 + preventDefault：抢在 Monaco 滚动处理与浏览器
  整页缩放（Ctrl+滚轮的浏览器默认行为）之前。
- 应用级快捷键帮助「Ctrl+滚轮」条目同步为「预览区缩放 / 代码区
  调编辑器字号」。
