# 2.0.155

> 发布日期：2026-08-25｜分支：`develop`
> 主题：**WEB UI 舒适度优化循环 63–66**——Sheet 行过滤、画布节点搜
> 索、搜索 Enter 居中选中、预览「适应窗口」。

## 内容

### 循环 63：Sheet 行过滤

- railroad 规则表等长列表定位全靠滚屏——区上方补过滤框（名称/数值/
  角色数据全字段匹配、只过滤显示不动数据、过滤中计数 N/M 与总行匹
  配数、Esc 清空）。**至此全部长列表编辑器过滤齐（Board/Sequence/
  Outline/Sheet）。**

### 循环 64：画布节点搜索

- 旗舰画布类编辑器（11 种节点-连线图）大图定位全靠拖屏——工具栏补
  搜索框：节点标签/id 匹配、命中保持原样、非命中降为 25% 不透明度、
  命中计数、Esc 清空、只影响显示不动数据。至此列表类+画布类搜索定
  位全覆盖。

### 循环 65：画布搜索 Enter 居中并选中

- 搜索框回车滚动居中首个命中节点并选中——定位 = 看见 + 到达；选中
  后形状/类型/属性等节点操作即刻可用。

### 循环 66：预览「适应窗口」按钮

- 大图找不到全貌时一键全图可见并居中（resize+fit+center）——与手动
  平移/缩放同级写状态（isDirty+双回调，重载可恢复），重置视图旁。
