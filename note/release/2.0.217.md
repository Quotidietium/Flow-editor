## 内容

### 循环 155：移动端 390px 弹层盘点

- **真修复 1：插件管理器对话框 Esc 关不掉**。`Dialog.Content` 上
  的 `onkeydown stopPropagation`（为防按键穿透到应用级窗口快捷键
  而加）把 Escape 一并吞掉，bits-ui 图层栈收不到——焦点在按钮上
  也关不掉对话框（探针实证）。修为仅放行 Escape 冒泡，其余键拦截
  照旧。全库排查无第二处同类。
- **真修复 2：主菜单触发器无可访问名**。图标-only 按钮此前无
  aria-label（读屏无声，测试只能 `nav button` 序号定位）；补上
  `aria-label/title="主菜单"`，Popover.Content 加
  `data-testid="main-menu-content"`。
- **常驻巡检**：`mobileSurfaces.spec.ts` 逐面打开 历史全屏接管/
  分享/插件管理器/导出菜单/主菜单，断言包围盒完整落在 390×844
  视口内 + 页面级无横向溢出 + 对话框 Esc 可关。盘点结果：既有
  各面几何全部合格（循环 20/82/97/104/105 的移动端正装有效）。
- 探针教训（记入实现注）：bits-ui 对话框开合带 zoom/slide 过渡，
  裸 boundingBox 会量到动画中途位移帧（曾把正常分享对话框误报为
  x=-144）——几何断言必须先等动画落定。
