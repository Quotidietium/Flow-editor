## 内容

### 循环 140：/view 只读页功能面补全

- 盘点 /view 页：缩放工具、回编辑器、下载 SVG/PNG、复制链接——
  唯缺**「复制图像到剪贴板」**：分享接收者把图贴进文档/聊天是最高
  频下游动作，免「下载 PNG → 再从文件插入」两跳。
- 复用编辑页同款能力：同一份干净 SVG 光栅化（长边 1080，剥 pan-zoom
  包装）→ `ClipboardItem` 写入 image/png。浏览器不支持 ClipboardItem
  时按钮不渲染（显式按钮与移动端「更多」菜单同步）。
- 顺带核验：/view 移动端「更多」菜单四项收纳完好；下载文件名沿用
  `diagramFileName`（默认时间戳名，观看者无自定义语境）。
