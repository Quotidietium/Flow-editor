# 2.0.162

> 发布日期：2026-08-26｜分支：`develop`
> 主题：**WEB UI 舒适度优化循环 84–86**——画布捏合缩放、属性对话框
> Enter 保存、编辑内容 Ctrl+Enter 保存。

## 内容

### 循环 84：可视化画布触屏捏合缩放

- 移动端没有 ctrl+滚轮——双指距离比折算目标倍率、锚点取双指中心
  （复用 `zoomAt` 指针锚定）；svg 已有 `touch-action:none`，浏览器不
  抢手势，passive 监听免 preventDefault。e2e 用合成 TouchEvent 实证
  外扩放大（≤2.5x 上限）、内收回落。

### 循环 85：可视化属性对话框键盘路径

- 属性（标题/meta 键）输入框此前无键盘提交，必须挪手点「保存」——
  Enter 即保存（`isComposing`+`keyCode 229` 双守卫，拼音输入法选词
  的回车不触发，MC 设计器循环 72 同款），Esc 取消不写回。

### 循环 86：编辑内容对话框 Ctrl+Enter 保存

- 多行文本域普通 Enter 换行照旧（语义不破），Ctrl+Enter 提交（IDE
  惯例），保存按钮 title 提示快捷键。
