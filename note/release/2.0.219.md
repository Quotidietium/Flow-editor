## 内容

### 循环 157：配置错误横幅「转到配置页」直达钮

- 配置 JSON 错误时横幅此前只有「重置为默认配置」——而用户看到
  「配置 JSON 错误」时的下一步几乎都是打开配置页改 JSON（Monaco
  json 校验的波浪线在那边），代码页在前时得自己想到换页。现在
  横幅给「转到配置页」直达钮，一键切到配置页。
- **仅代码页在前时出现**——配置页已在前则波浪线就在眼前，直达
  无意义（与「定位到错误行」只在代码错误+代码页在前时出现的
  既有门控同思路）。
- 双端同走 state 的 `editorMode`（桌面 Monaco / 移动 CodeMirror
  一致生效）。
