## 内容

### 循环 133：导出尺寸偏好记忆

- PNG 尺寸**模式**（自动/宽度/高度）与**尺寸值**跨会话保持
  （localStorage 键 `exportSizeMode` / `exportImageSize`）——反复
  导出同一目标尺寸（如固定 1440 宽）免每次重设。
- 读取侧兜底：手改 storage 的非法模式/数值（<3 或 >10000、非有限
  数）回默认（自动/1080），与预览背景的读取侧兜底同款先例；导出
  时仍有 `exportCanvasSize` 钳制双保险。
- **导出倍数刻意保持会话级**（沿用既有决策注释）：持久化一个被
  遗忘的 4x 会在下次会话产出意料之外的巨型文件——e2e 钉住该语义
  （2x 刷新后回 1x）。
- 顺带移除旧的 `if (!imageSizeMode)` 兜底 effect（sanitize 已覆盖）。
