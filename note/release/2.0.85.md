# 2.0.85

> 发布日期：2026-08-20
> 主题：可视化编辑器支持全部 Mermaid 图类型（新增 24 类，合计 31 类）

## 新增

- **全部图类型可视化编辑**：以 `@mermaid-js/examples` 全部 31 个类目 + 应用注册的
  zenuml 外部图为基准（逐一实测 `mermaid.parse` 通过），新增 24 个图表类型适配
  （`src/lib/util/visualEditor/kinds.extra.ts`），Visual 标签现在可直接导入并编辑：
  - 分组列表族：用户旅程（journey）、时间线（timeline）、看板（kanban）、甘特图
    （gantt）、Cynefin 框架、饼图（pie）、报文图（packet-beta）、雷达图（radar-beta）、
    XY 图表（xychart-beta）、维恩图（venn-beta）、事件建模（eventmodeling）
  - 缩进树族：树视图（treeView-beta）、矩形树图（treemap）、鱼骨图（ishikawa）、
    泳道图（swimlane-beta）
  - 节点-边族：桑基图（sankey-beta）、需求图（requirementDiagram）、块图
    （block-beta）、C4 图（C4Context/Container/Component/Dynamic/Deployment）、
    架构图（architecture-beta）、Git 图（gitGraph）、ZenUML
  - 坐标驱动族（拖拽直接改写代码中的 `[x, y]`，真正的所见即所得）：四象限图
    （quadrantChart）、Wardley 地图（wardley-beta）
  - 语法规则族：铁路图（railroad-ebnf/abnf/peg/IR 四种头共用，规则名+表达式编辑）
  - 唯一排除：`info` 调试图（仅渲染 mermaid 版本号，无用户内容）
- **节点类型调色板**：按类型切换节点语义（C4 人员/系统/容器…、旅程任务/分组、
  看板卡片/列表、雷达轴/曲线…），节点上方显示角色角标
- **图表属性对话框**：编辑标题与类型级元数据（gantt 日期格式、quadrant 轴/象限
  标签、radar 最值、block 列数、wardley 画布尺寸）
- **frontmatter 逐字节保留**：`--- … ---` 配置块（kanban/radar/packet/treemap
  官方样例形态）跨往返不丢失
- 每类保持「往返不动点」契约；全部生成代码经真实 `mermaid.parse` 验证合法

## 关键实现

- `VNode.role/roleData`、`VEdge.role/roleData`、`VGraph.title/frontmatter/meta`
  通用载荷；`KIND_SPECS` 31 条能力表（canLink/nodeTypes/metaKeys）驱动工具栏
- git 提交重放（branch/checkout/commit/merge 序列从节点序+边角色重建，悬空
  merge 自动降级）；architecture 边端口双侧强制（`A:L --> R:B`）
- 无连线语法的类型隐藏锚点并拦截连线手势；分组类型选中分组后添加自动挂接
- 不可信输入加固：新解析器继承超长单行跳过；越界坐标夹取 [0,1]
