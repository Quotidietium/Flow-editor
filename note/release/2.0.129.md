# 2.0.129

> 发布日期：2026-08-23
> 主题：MC 进度设计器示例插件——流程图一键导出 Paper 成就插件（Maven 工程 zip）
> ＋插件前端 sandbox 透传修复（allow-downloads）

## 内容

### MC 进度设计器（`plugins/examples/mc-advancement.mjs`，~1900 行自包含插件）

把流程图变成可编译的 **Paper 1.21.11 成就插件**（参照
`REF/Minecraft-Achievement-plugin` 泛化）：

- **图 ↔ 成就映射**：节点=成就（标签=名称）、边=parent 承接、形状=框架
  类型（矩形=任务/圆角=目标/菱形=挑战）、**连通分量=成就栏**（一张图可画
  多棵互不相连的树 → 单插件多标签页，无入边节点=栏根 tick 自动授予）。
- **元数据存 frontmatter**：`mcadv` 键（JSON 写法，YAML 子集——实测
  mermaid parse/render 均兼容自定义嵌套键），可视化编辑器逐字节保留，
  画布拖改不丢元数据；URL 分享/History 快照自动继承。
- **21 种触发方式**（触发器注册表同时驱动前端参数表单、config.yml 键与
  Java 监听器分支生成，**只生成用到的分支**）：加入/挖掘/放置/进食/击杀/
  钓鱼/到达高度/合成/附魔/交易/驯服/繁殖/入睡/死亡/等级/拾取/聊天关键词/
  完成其他进度/累计在线/原版统计/仅命令授予。高频事件（移动）5 tick 节流；
  统计类走 `Registry.STATISTIC` 轮询（1.21 的 Statistic 已注册表化，
  无 `valueOf`）；PlayerDeepSleepEvent/PlayerTradeEvent 在
  `io.papermc.paper.event.player` 包（mvn 实测修正）。
- **插件前端属性面板**（frontend hook，data: 内嵌单页）：成就/成就栏/
  插件三级设置、触发器下拉+动态参数表单、校验面板（环/多根/id 冲突/
  参数缺失/孤儿元数据，点击定位）、新增成就与成就栏、id 改名级联、
  删除转挂下级、`allow-downloads` 沙箱内直接导出。核心逻辑经
  `coreFactory.toString()` 注入前端，与 export 钩子共享同一实现。
- **一键导出 zip**（导出菜单或前端按钮均可）：store 模式零依赖 zip
  （固定 DOS 时间戳，同输入逐字节一致），含 pom.xml / paper-plugin.yml /
  config.yml / pack.mcmeta / 全部成就 JSON（含每栏可选「大满贯」汇总成就：
  N 条件 + requirements + 经验奖励）/ 7 个 Java 文件（bootstrapper 数据包
  注册、枚举、授予服务、事件监听器、泛化计数存储、查询+grant 命令）/
  README（自动成就清单）。
- 设计文档：[`note/mc-advancement-plugin.md`](../mc-advancement-plugin.md)。

### 插件前端 sandbox 透传修复

`FrontendHook.sandbox` 自 2.0.92 起存在于类型、2.0.128 起经注册表转发，
但 edit 页渲染 iframe 时写死沙箱串——现已透传（缺省值不变）。声明
`allow-downloads` 的插件前端（如本插件）可在页内直接下载导出物。

## 安全复核

- 插件信任级不变（用户本地安装）；前端 iframe 沙箱缺省串不变，
  `allow-downloads` 需插件显式声明且仅影响下载手势。
- 导出产物为纯文本 zip（store 模式），无外部请求；frontmatter 元数据经
  JSON.parse 容错解析，损坏时给出明确错误而非崩溃。
