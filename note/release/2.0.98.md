## API 逻辑缺陷修复

- **URL 分享链接 hash 覆盖竞态**（2.0.93 引入的回归）：`loadState` 因插件
  输入管道改为异步（动态 import），但 `initHandler` 未等待——
  `initURLSubscription` 的立即 flush 会在分享态落地前把**默认态**写入
  hash，窗口内复制链接会拿到错误内容。修复：`loadState` 返回 Promise、
  `loadStateFromURL` 透传、`initHandler` await 后再订阅。新增
  `state.loadState.test.ts` 2 项回归测试（发布时序 + flush 后 hash 解码
  内容即分享态而非默认图）
