## 内容

### 循环 128：历史两版本互比

- 循环 127 的「与当前对比」只能比单个版本 vs 当前编辑器；现在
  对话框内新增**「对比对象」下拉**：默认「当前编辑器」，可切换为
  本页签任意历史版本——**任意两版本互比**（如「上次保存」vs「上
  上次」），免恢复中转、免覆盖当前编辑内容。
- 方向语义显式化：标题改为「版本对比：A → B」，说明文案标注
  「增 = 右侧新增，删 = 左侧独有」；切换基准后增删统计与差异行
  实时翻转。
- 实现：diff 状态升级为 left（点按钮的条目，固定）/ right（可切换）
  双槽模型；候选列表 = 当前编辑器 + 本页签全部条目（reactive——
  对话框打开期间当前编辑器代码变化会实时反映到「当前编辑器」项）；
  对比对象条目被删时回退到「当前编辑器」。零依赖 LCS diff 复用
  `util/lineDiff`，400 行渲染上限与全量统计语义不变。
