## 内容

### 循环 147：差异行上下文折叠

- 版本对比对话框在长段未变行时不再整屏平铺：非差异行两侧各保留
  3 行上下文，其余连续相同行收拢为 **「··· 已折叠 N 行相同内容 ·
  点击展开 ···」** 分隔条（GitHub 式），点击即展开为普通行。
- 折叠判定纯函数 `collapseContext`（`lineDiff.ts`）：折叠段少于
  4 行直接显示（太碎的折叠反而干扰）；**头尾各留 3 行**——两版本
  完全一致（全 same）时不会只剩一条折叠条。
- 展开状态为对话框会话级：切换对比对象 / 对调方向 / 重开对话框
  均复位为折叠（`SvelteSet` 记录展开的块 key）。
- 与既有能力并存：双行号列、悬停/键盘单行复制、复制差异、
  MAX_DIFF_ROWS=400 截断（先截断后折叠，截断提示语义不变）。

### 配套修复：embed 沙箱 iframe 用例端口硬编码

- `embed.spec.ts` 沙箱 iframe 用例的 iframe src 硬编码
  `http://localhost:3000`——`DEV_PORT` 覆盖（循环 146）后 dev
  server 不在 3000 时 iframe 整页空白、用例必挂；改为注入
  `baseURL` fixture 跟随端口。
