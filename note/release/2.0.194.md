## 内容

### 循环 132：对比对话框迭代

- **一键对调方向**：「版本对比：A → B」反过来看（B → A）不再需要
  重开对话框换基准——对话框内「对调」一键完成，标题与增删统计
  实时互换。
- **对话框内直达恢复**：对比中发现要的就是左侧旧版时，「恢复左侧
  版本」一键回填编辑器并关闭对话框——免关闭再回列表找条目。
  左侧是「当前编辑器」时无恢复对象，按钮自动隐藏；恢复走既有
  `restoreHistoryItem`（全量替换 + toast 反馈）。
- 实现：diff 状态从「left 快照 + right id」重构为**双槽 id 模型**
  （left/right 皆引用候选列表，'' = 当前编辑器），对调即交换两 id；
  左侧条目引用保留完整 State（恢复所需），条目被删时回退「当前
  编辑器」。零依赖 LCS 与渲染上限语义不变。
