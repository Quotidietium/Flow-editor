# 2.0.153

> 发布日期：2026-08-25｜分支：`develop`
> 主题：**WEB UI 舒适度优化循环 55–58**——配置 JSON 智能提示、历史条
> 目代码速览、拖拽文件打开、Sequence 消息过滤。

## 内容

### 循环 55：配置 JSON 智能提示

- 配置模式敲键名出 `theme`/`themeVariables`、枚举位出 `dark`/`forest`：
  Monaco JSON worker 挂手工精简 schema——键名带中文说明、theme/look
  枚举与常量表同步（不各写一份漂移）、securityLevel 四档、布局键
  number 类型；`enableSchemaRequest=false` 全程离线、
  `additionalProperties` 放开——只做提示，未知 Mermaid 键照常可写。

### 循环 56：历史条目代码速览

- 自动条目名是随机 slug、手动条目也可能同名——名称悬停 title 补
  「名称 · 压缩代码开头」（单空白、限 120 字符），随 entriesWithUrl
  一次派生不逐行重复算。

### 循环 57：拖拽文件到工作区直接打开

- 抽出 `loadFileIntoEditor` 共享链（插件导入钩子优先 → 内置
  parseOpenedFile 兜底 → 输入转换管道 → 配置安全门），「打开」按钮与
  drop 放落同路径；拖入时工作区 ring 高亮（enter/leave 计数器防子元
  素抖动）。监听挂 window 而非容器 div：元素级 drag 事件触发 a11y 警
  告（键盘等价路径本就在「打开」按钮），且 window 级 preventDefault
  顺带堵掉「漏拖导航走丢现场」的浏览器默认行为。

### 循环 58：Sequence 消息过滤

- 长时序图定位消息全靠滚屏——消息区头部补过滤框：消息内容+源/目标
  参与者名匹配、只过滤显示不动数据、过滤中计数 N/M、Esc 清空、零匹
  配提示。Board 卡片过滤同款交互。
