## 内容

### 循环 162：连线拖拽悬停目标高亮

- 拖连线过程中，指针悬停在合法目标节点上时该节点出现主色虚线
  圈——此前能否连上只有松手后才知道（落空即无声取消）。悬停
  空白/源节点自身/stateDiagram 禁连伪节点时不出圈，口径与落点
  判定完全一致。
- 反应式链路：linking.cursor 的 $state 深响应 → linkHoverId 派生
  → 节点组后的无损层 rect（pointer-events:none 不抢手势）。
