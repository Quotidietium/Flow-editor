## 内容

### 循环 15：移动端编辑器头部工具紧凑化

- **实测发现真溢出**（390px 视口 boundingBox 实证：头部内容超出卡片右缘

### 循环 16：透明背景扩展到 SVG 导出

- SVG 下载随「透明背景」勾选去掉根元素内联背景色（判别点精确到根
  `<svg>` 的 style——mermaid 自带 CSS 也含 background-color 字样）。

### 循环 17：历史条目图表类型徽章

- 条目行显示本地化类型名（复用可视化模型 `detectDiagramKind` 首行探测
  - `KIND_SPECS.label`，frontmatter/注释跳过），长列表扫读定位更快。

### 循环 18：错误条「复制错误内容」
