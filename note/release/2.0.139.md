## 缺陷与修复

### ① 非根节点改名「跳到另外一个成就栏」（结构损坏）

- 根因：`renameNode` 只迁移「根节点改名」的 `tab.members`——非根成员
  改名后旧 id 滞留成员表，`rebuildCode` 的 subgraph 分组不含该节点
  （平铺输出），且一端在组内的连线被生成侧静默丢弃；重建分析时该节点
  成为独立连通分量 = 自成新栏，其子级被重挂到原栏根。
- 修复：全部栏的 `members` 统一做 id 迁移（根节点另同步 rootId/rootNid）。
- 判别性 e2e：改名后仍单栏、徽章数不变、写回 subgraph 仅一个、重读
  结构完整（旧代码下该用例必失败）。

### ② 文本框输入问题（一簇，均源于「每次 onchange 整块重建面板」）

| 症状                                        | 根因                                           | 修复                                     |
| ------------------------------------------- | ---------------------------------------------- | ---------------------------------------- |
| 点下一个输入框/按钮要点两下                 | blur 触发的 innerHTML 重建吞掉进行中的点击     | 值类编辑定向刷新（树+校验），表单不重建  |
| 长表单编辑底部字段后跳回顶部                | 面板/树滚动复位                                | `#panel`/`#treeList` 重建前后保持滚动    |
| 树搜索中文输入法被打断                      | 搜索框随列表每次重建销毁（合成会话无法跨元素） | 搜索框常驻不重建；清过滤时同步清空其文本 |
| 数值输入与实际值隐性不一致（如 2.5 实为 2） | parseInt 后不回写显示                          | 规范化后回写输入框                       |

另：根节点表单补「事件时当前代解析」（孤儿闭包家族防线补全——值类
编辑不再整页重渲后必需）。
