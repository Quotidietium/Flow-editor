## 审计范围

本轮覆盖三个面：MCP bridge（postMessage JSON-RPC）工具参数验证、Share
对话框与 serde 的 base64/pako 降级路径、notify/toast 队列长会话行为。

## 缺陷与修复

**bridge 文本参数无尺寸上限（不可信输入加固，修复 + 判别性单测）**：
`set_code`/`set_state` 只验类型不验尺寸——URL 输入通道有浏览器 URL
长度上限天然约束，而 postMessage 通道没有任何约束：一个巨型字符串会
直入状态网关的同步 `JSON.stringify` + localStorage 写（主线程冻结/配
额炸）。修复：`bridgeText` 统一验证（类型 + `MAX_BRIDGE_TEXT_LENGTH`
= 5M 字符，与上传文件同量级），超限返回 `-32602`；顺带修正
`set_state` 对非字符串 `mermaid` 从「静默丢弃」改为按 schema 拒绝。

configGate.test.ts 新增 2 用例：超长 code 对两个工具均返回 -32602
且**零 store 写入**；非字符串 mermaid 被拒。判别性验证：暂存修复后
套件失败（新导出不存在）、恢复后 18/18 通过。

**测试抗负载加固**：configGate 五个用例显式 20s 超时——真实 mermaid
配置导入使单用例 ~6s，贴着默认 10s 上限，并行满载下会抖动超时（本轮
实测一次）。

## 审计通过项

- **serde 降级路径**：pako 读侧 20MB inflate 上限（r7）+ legacy 无前
 缀 base64 读取有 pinning test（r12）；base64 读侧无独立上限为已接
  受残余（浏览器 URL 长度天然限制，r7 报告记录）；Share 对话框自身
  无降级逻辑（嵌入 URL 由 embedCode 生成、分享输入框直接用网关维护
  的 location.href），主题/外观值域受 option 列表约束、无注入面
- **export format 宽容降级**：未知 format 回落 code，非字符串不崩溃
- **bridge 响应面**：响应只回发请求方 origin（opaque origin 回
  `*`，r 2.0.94 已修）；`callEditor` 超时 reject 已 settle 无效但
  timer 5s 自然过期，无累积
- **notify/toast 长会话**：`visibleToasts=4`（r18）在位；sonner 自动
  dismiss + 队列只保留可见项，长会话无 DOM 堆积；notify/prompt 为薄
  封装无状态
