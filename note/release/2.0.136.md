## 内容

### 本地化（mc-advancement 1.8.0）

`meta.localization` 开关（默认 **off**，既有工程行为不变）：

- **on 时**：advancement JSON 的 title/description 走
  `{"translate": "<ns>.advancement.<id>.title|.description"}`；生成
  `data/<ns>/lang/zh_cn.json` 与 `en_us.json`（键覆盖栏根/全部成就/大满贯
  的标题与描述）。英文值取自表单英文输入（成就 `en`/`enDesc`、栏
  `enTitle`/`enDesc`、大满贯 `completionistEn`/`EnDesc`），**缺省回填
  中文**——客户端任何语言都显示译文而非键名。生成的插件随玩家客户端
  语言显示进度名。
- **前端**：插件设置新增开关；开启后成就/栏/大满贯表单出现英文输入
  （placeholder 注明「留空回填中文」）。
- **逆向导入**：外部数据包的 translate 标题经 `lang/zh_cn.json`（缺失
  回落 en_us）还原为可读名称——单测验证剥离溯源后愚公移山/栏名正确
  还原；自家导出走溯源元数据完整往返。
- lang 文件为 `.json`，桌面编译链白名单天然放行（随 jar 打包）。

### 循环 23：生成 Java 并发路径审查（三处真实修复）

逐行审出三处并发缺陷（异步事件 AsyncChat 与主线程并发时暴露）：

1. **ProgressStore.add 丢更新**：`getOrDefault+put` 读改写非原子——异步
   线程与主线程并发计数同一玩家会丢；改 `map.merge(key, delta,
Integer::sum)` 原子累计。
2. **AchievementService 缓存容器非线程安全**：`EnumMap` 在并发
   computeIfAbsent 下可能损坏；改 `ConcurrentHashMap`。
3. **chat_keyword 跨线程调用 Bukkit API**：AsyncChatEvent 在异步线程
   触发，直接 `service.award(...)` 调用非线程安全的进度授予 API——
   整个检查与授予 `scheduler.runTask` 调度回主线程（listener 补存
   plugin 引用）。

单测断言生成源码（merge/ConcurrentHashMap/runTask）+ javac 15/15 +
实机回归 12/12（加载/自检/命令链无破坏）。suggest 补全为客户端 TAB
行为，控制台不可实机验证（记录）；虚拟滚动已有 600 节点实测数据支撑
不做（循环 15 报告）。

### 循环 24：onDisable/落盘路径加固（实机取证驱动）

实机探针逐层取证后落地三件事：

- **save() 捕获 RuntimeException**：目录缺失等场景 YamlConfiguration 抛
  IllegalArgumentException 而非 IOException——旧 catch 会静默吞掉，
  落盘失败无任何痕迹；现两类异常都记日志。
- **onDisable 可观测化**：无条件打「进度计数已保存到 progress.yml」
  （成功路径），失败路径 WARNING——静默失败从此可诊断。实机 14/14
  中「日志证词」断言即依赖它。
- **实机验证事实链**：stop 路径 onDisable→save 成功（日志证词）；
  /reload 在此构建的控制台下**不可稳定驱动**（stdin 偶发吞行 +
  带参命令解析失败 `[HERE]`），相关断言条件化并限定插件名前缀
  （旧断言把 REF 示例插件的同名日志行误计，属假阳）。

### 循环 25：面板↔代码边界一致性（孤儿闭包家族第二例根治）

- **renameNode 根跟随缺陷**：根节点改名后 `tabs[].rootId/members` 未同步
  ——rebuildCode 用旧 rootId 生成 subgraph，根掉出分组、显示退化平铺；
  已同步更新（rootId/rootNid/members 映射 + meta.tabs 键迁移）。
- **renderTabForm 孤儿闭包（根治）**：与循环 14 bindNodeForm 同类——
  栏设置表单的 handler 闭包捕获旧代 root/tm，写回触发 rebuildCode 整替
  analysis 后，改名写进**旧代对象**（当前代 r2 未变 → subgraph 空 +
  孤儿 r2 + 同名警告三连锁）。事件时动态解析当前代（curTabMeta/
  findNode）。e2e 多栏用例固化完整链（改名→写回→重新读取→校验通过→
  subgraph 跟随 + 成员计数保持），复跑稳定。
- **config 热重载核对（通过）**：listener/command 在 enable 时快照
  `plugin.getConfig()`；Paper `/reload` 走 disable→enable 全链路 →
  重新构造 → 新 config 生效——与 README「重启或 /reload 生效」声明一致。

### 循环 26：孤儿闭包家族第三处根治 + suggest 前缀过滤 + 组合回归

- **renderSettings 孤儿闭包（家族第三处，根治）**：设置表单 handler 闭包

### 循环 27：addNode subgraph 入组缺陷 + 定时任务取消加固

- **addNode 入组缺陷（真实，subgraph 模式）**：新成就只入 nodes/edges，
  未进所属栏 `tab.members`——rebuildCode 分组不含它，写回后被挤出到
  **独立的分量栏**（平铺模式无害，subgraph 模式结构错乱）。修复：新
  id 同步 push 进宿主栏 members。awardCriteria 多条件补齐路径源码
  复审通过（award 补齐全部 remaining，completionist 单条件门控，与
  REF 同构）。
- **定时任务句柄 + onDisable 显式取消**：Bukkit 对同步任务会在插件
  禁用时自动取消，防御式持有 `BukkitTask` 句柄（statTask/saveTask）
  并在 onDisable `cancel()`——reload 竞态窗口内确保零泄漏。字段声明
  为无条件（saveTask 任何样本都有；首版困在统计块内致非统计样本编译
  失败，被 javac 单触发器探测当场拦下）。
