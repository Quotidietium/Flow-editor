## 内容

### 循环 47：GitEditor 操作行复制按钮

- git 图重复 commit 是常态——一键紧邻原位重放同分支/同类型拷贝
  （merge 行连 mergeFrom 来源边克隆）；提交 ID 与标签须唯一，新行留空
  另填——复制的是「这一步操作」而非同名提交。

### 循环 48：Outline 子树复制按钮

- mindmap/treeview/treemap/ishikawa/swimlane 五类大纲的重复分支（相似
  分类/鱼骨分支）此前需逐级重建。`duplicateRow` 深克隆整棵子树为下一
  个同级行：DFS 展示序重映射全新 id、根行按节点序成下一根、父子边按
  DFS 序保持各父孩子序；拷贝根自动聚焦立即可改名。

### 循环 49：Sheet 行复制按钮

- pie/packet/radar/xychart/venn/eventmodeling/railroad 七类表格的重复
  记录（相邻切片/相似曲线）一键紧邻原位插入全等拷贝（新 id、detail/
  roleData 同拷、节点序=行序），拷贝自动聚焦。**至此六类可视化编辑器
  （画布 Ctrl+D / Board / Sequence / Git / Outline / Sheet）复制能力
  全家桶齐。**

### 循环 50：/view 只读页 PNG 下载

- 循环 41 的 SVG 之外的第二个格式：Word/聊天工具不吃 SVG 的场合免回
  编辑器。`rasterizeSvgMarkup` 复用同一份干净 SVG（剥 pan-zoom 变换），
  按 viewBox 等比缩放长边 1080、10s 超时、防重入锁。
