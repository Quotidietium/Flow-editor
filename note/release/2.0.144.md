# 2.0.144

> 发布日期：2026-08-25｜分支：`develop`
> 主题：**WEB UI 舒适度优化循环 19–22**——Ctrl+S 快捷收藏、图元搜索、
> 导出菜单分组、历史标签计数。

## 内容

### 循环 19：Ctrl+S 快捷收藏到历史「已保存」

- 编辑页拦截 Ctrl+S（preventDefault 浏览器保存网页）：一键把当前状态
  收藏进历史「已保存」，去重提示与保存按钮一致。
- **排障记录（防再犯）**：冷启动 dev server 水合需 4–6 秒（107 模块 +
  Monaco/mermaid 转换），e2e 必须先等就绪标记（`__FLOW_EDITOR_API__`
  或 URL `#pako` hash）再交互——此前探针在 1–1.5s 判定，一路误判到
  「onMount 全灭」；长驻手动 dev server 跨编辑供陈旧内嵌路由模块
  （SvelteKit dev 在 server 启动时内嵌路由节点），e2e 前必须清场。

### 循环 20：插入图元面板搜索过滤

- 「插入 ▾」面板顶部搜索框：匹配图元中文名/role（C4、cynefin 等 6 类
  图元为项目内最多），Esc 清空、关闭重置、打开 autofocus；列表加滚动
  上限与无匹配提示。

### 循环 21：导出菜单分组标题

- 9+ 个导出项按「图像 / 文档与数据 / 插件导出」分组（插件组仅在有
  插件导出项时显示），扫读定位更快。

### 循环 22：历史标签页条目计数

- 已保存 / 时间线 / 修订版本标签显示反应式计数（`historyCounts`），
  增删收藏即时更新。
