> 发布日期：2026-08-25｜分支：`develop`
> 主题：**WEB UI 舒适度优化循环 31–34**——当前图类目高亮、模板生效打勾、
> 复制 Mermaid 源码、空态收藏引导。

## 内容

### 循环 31：示例卡片高亮当前图类目

- `detectDiagramKind` 实时识别当前代码的图类型，对应类目按钮 ring 高亮 +
  `aria-current`（railroad 四变体、swimlane 无类目不高亮）——一眼看出
  正在编辑哪类图。踩坑：sr-only 文本会改变按钮可访问名撞 e2e 选择器
  （高亮交给 aria-current 与视觉环）。

### 循环 32：配置模板菜单对当前生效项打勾

- `isConfigSubset` 子集匹配：模板的每个叶子值都在当前配置中出现即视为
  生效（允许多出其它键）——与深合并语义一致，主题/风格/版式可同时
  多个打勾。

### 循环 33：导出菜单「复制 Mermaid 源码」

- 源码本体一键入剪贴板——粘进聊天 / Issue / 文档的最短路径，免下载
  .mmd 中转；置于「文档与数据」组 .mmd 项旁。

### 循环 34：历史空「已保存」立即收藏引导

- 空态提供「立即收藏当前图表」CTA——新用户第一条收藏零查找成本；
  点击即出现条目并隐藏引导。
