## 审计范围

本轮覆盖状态网关的三个一致性边缘：桌面编辑器空文本上报、可视化编辑器
写回路径、插件 blob URL 生命周期。

## 缺陷与修复

**清空编辑器不上报网关（桌面端数据完整性缺陷，修复 + 判别性 e2e）**：
DesktopEditor 的 `!newText` 守卫把「清空为空串」的编辑吞掉——编辑器显示
空文档，但持久化 state.code 仍是旧图（探测实证：Ctrl+A+Backspace 后
codeStore 原封不动），导出/分享 URL/历史快照全部携带用户已删掉的内容；
MobileEditor（CodeMirror）则正常传播空文本，跨端行为不一致。修复：移除
`!newText` 分支，空文本与其他编辑一视同仁过网关（空代码走正常解析错误
路径，3s 防抖后显示语法错误横幅——与移动端一致）。

e2e 回归（errorDisplay.spec.ts「clearing the editor clears the
persisted code」）：清空→横幅出现→localStorage code 长度为 0。判别性验
证：暂存修复跑该用例失败（横幅 10s 不出现）、恢复修复通过。

## 审计通过项

- **可视化编辑器写回走网关**：`syncCode`→`updateCode(..., {updateDiagram:
  true})`，无绕过路径；位置/尺寸记忆写入有 100KB 上限
- **插件 blob URL 生命周期**：动态 import 完成后 10s 释放 URL——模块此
  时已评估入内存，释放安全；失败路径经 finally 同样释放
