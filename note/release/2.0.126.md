# 2.0.126

> 发布日期：2026-08-22
> 主题：非流程图重写补证——剩余 15 类逐类型导入冒烟 e2e（30/30 全覆盖）

## 内容

新增 `visualEditorSmokeAllKinds.spec.ts`：对没有专项交互用例的 15 个非
流程图类型逐一轮转「粘贴代码 → 进入可视化 → 断言 → 退出」，每类断言：

- 打开了**正确的编辑器形态**（board/sheet/outline/canvas 的 testid）；
- 导入了内容（看板卡片 / 表格与大纲行 / 画布节点实际渲染）；
- 代码头保留（生成往返未丢类型）。

覆盖：gantt/timeline（board）、packet/railroad/venn/xychart（sheet）、
ishikawa/swimlane/treeview（outline）、architecture/block/c4/requirement/
sankey/wardley（canvas）。加上此前各专项规格（journey/kanban/cynefin/
pie/radar/eventmodeling/mindmap/treemap/sequence/zenuml/git/state/er/
class/quadrant），**全部 30 个非流程图类型的可视化编辑至此都有 e2e
证据**。

踩坑记录：可视化标签激活时 Monaco 不接受剪贴板粘贴（左栏编辑器让位），
逐类型轮转必须在进入可视化之前贴码。

## 验证

- 新规格 1/1 通过（15 类型单用例轮转，本机 Windows 11）；
- eslint/prettier 通过。
