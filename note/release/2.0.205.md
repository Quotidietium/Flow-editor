## 内容

### 循环 143：代码专注模式（与预览专注对称）

- 循环 126 的「预览专注」收编辑区看图；本循环对称补上**「代码专注」**
  （编辑器卡操作区新 Toggle，收起右栏预览区、编辑区占满）——大段
  写代码时沉浸不被渲染拖注意力。
- **两态互斥**：预览专注（收编辑栏）与代码专注（收预览栏）同时开启
  只剩工具栏区，无意义——任一态开启时互清另一态。预览专注开启时
  编辑栏（含代码专注钮）整个收起，「预览专注下直接开代码专注」物理
  不可达，互斥实为防御性状态保护（e2e 无独立路径用例，注释说明）。
- 会话级开关（与预览专注/导出倍数同先例）；退出后预览 pane 重挂、
  状态从网关恢复、代码保持。
- **实现坑（已入册）**：切换钮 `bind:pressed` 与 `onclick` 同时翻转
  同一状态 = 双翻转回原值，表现为间歇性「点了没反应」——互斥逻辑
  放 `onPressedChange`，本态翻转只交给 bind。
