# 2.0.115

> 发布日期：2026-08-21
> 主题：第 28 轮审计——可视化剪贴板 paste 路径 / Monaco undo 跨 model / persist 写放大

## 审计范围

本轮覆盖三个面：VisualEditor 剪贴板 paste 路径的不可信内容处理、
Monaco undo 跨 model 切换语义、persist 写放大面。

## 缺陷与修复

**运行时坐标越界使位置记忆被静默丢弃（修复 + 判别性单测）**：
`sanitizePositions`（±10000 夹取，r15）只在**加载** localStorage 位置
表时应用，运行时写入路径不夹取——连续 paste（每次 +24）、长按方向键
nudge、连续 Ctrl+D 都能把坐标推出边界；`rememberPositions` 把越界值写
入持久化，下次启动 `sanitizePositions` 整条**静默丢弃**，用户排列跳回
自动布局（数据完整性缺陷）。修复：提取 `clampPosition`（与
`sanitizePositions` 共享 `POSITION_BOUND`，杜绝两处界值漂移），
`pasteClipboard` 的 +24 偏移与 `rememberPositions` 的写入统一夹取。

model.multikind.test.ts 新增 2 用例：越界夹取契约；
`clampPosition` 输出必须被 `sanitizePositions` 接受（界值一致性）。
判别性验证：暂存修复后套件失败、恢复后 27/27 通过。

## 审计通过项

- **剪贴板 paste 路径**：剪贴板为内部内存载荷（模块 `$state`，不从
  系统剪贴板读数据），copy 源于当前 graph、paste 经 `remintIds` 重铸
  id（悬挂边自动丢弃）；系统剪贴板文本只能经 Monaco→网关→`parseCode`
  进入，该路径已有行宽/尺寸防线。无不可信注入面
- **Monaco undo 跨 model**：mermaid/json 两 model 各持独立 undo
  stack，切换经 `executeEdits`（`isUpdatingFromState` 抑制回声）；
  undo 产生的变更正常过 `onUpdate`→网关；`currentText` 与 effect 的
  newText 收敛无循环；undo 到底→空文本→与 r24 空编辑语义一致
- **persist 写放大**：网关每次 update 同步全量写 codeStore 为
  upstream 性能特征（打字风暴 stress 实测无错误/无卡死）；位置/尺寸
  记忆有 100KB 写入上限 + 手势级频率；历史 store 写频率为 60s/手动；
  配额行为有 persist.quota.test.ts 钉死
