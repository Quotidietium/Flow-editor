# 2.0.140

> 发布日期：2026-08-25｜分支：`develop`
> 主题：**持续实机体验修复（循环 72–73）**——MC 进度设计器输入与
> 结构可诊断性三补 + 一处静默收编显式化，插件 v1.10.2。

## 内容

### 循环 72：输入与结构体验三补

- **Enter 即提交**：面板无 `<form>`，此前文本/数值输入按 Enter 没有任何
  反馈（用户常以为已保存）。新增 `bindEnterCommit`——文本/数值输入回车
  即触发 change 提交路径；`isComposing` + `keyCode 229` 双守卫，输入法
  拼音选词确认的 Enter 不误触。
- **校验面板滚动保持**：`#issues` 与面板/树同款——编辑中校验列表刷新
  不再把正在查看的位置跳回顶部。
- **结构操作不变量 e2e**（防回归装甲）：双栏链图上依次执行叶改名 /
  中段改名（有子级）/ 添加下级 / 改挂栏根 / 写回 + 重读往返，逐断言
  栏数与徽章计数稳定（2.0.139 修复的「改名跳栏」家族从此有整链路守卫）。

### 循环 73：静默收编显式化 + 搜索 Esc

- **subgraph id 与既有节点重名**：手写代码中组 id 恰与其它组内/组外
  节点同名时，该节点此前被**完全静默**地收编为该栏根（归属迁移、名称
  被栏名覆盖、指向它的连线按跨栏忽略）——用户只见节点从原栏消失、
  莫名多出一栏。现给出可定位警告（tabId），并单测实证旧行为、新警告
  与常态（组 id 唯一）不误报。
- **树搜索 Esc 清过滤**：大图里清词回全量是高频动作；合成期间 Esc 属
  取消候选词，不清过滤（isComposing 守卫）。e2e 用 Esc 钉住清空链路。
