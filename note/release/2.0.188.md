## 内容

### 循环 126：布局舒适度

- **专注模式**：预览工具栏新增开关（编辑页专属；移动端滑屏布局本就
  整屏切换，不参与）——收起左栏编辑区，预览/可视化画布占满工作区，
  演示与检视大图免拖分隔条。**会话级开关不持久化**：被遗忘的专注=
  「编辑器不见了」的迷惑，刷新即回（与预览暂停同先例）。退出后
  Monaco 重挂载并从状态网关取回代码，零数据面。
- **分隔条双击复位**：编辑区/预览分隔条悬停显形（此前完全隐身——
  拖拽能力本身不可发现），双击回到编辑栏 30% 初始宽度（autoSaveId
  持久的布局被拖乱后免手动归位）；悬停提示标注两种操作。
- 实现要点：`editorPane` 改 `$state` 声明——专注模式会卸载/重挂
  编辑栏，`bind:this` 的 undefined 回写必须可反应（mobile
  `resize(50)` effect 依赖此引用，svelte-check 警告发现）。
