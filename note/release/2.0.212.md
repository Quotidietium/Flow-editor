## 内容

### 循环 150：行内字符级差异高亮（GitHub 式）

- 版本对比里「改了一个词」不再是整行红/整行绿：配对的 del/add 行
  （del 段紧接 add 段，第 i 个 del 配第 i 个 add）剥离**公共前缀与
  公共后缀**，仅实际改动的中段上底色（删=红底、增=绿底，圆角
  半透明），其余文本原色——配置微调、节点改名一眼定位。
- 纯函数 `attachInlineDiff`（`lineDiff.ts`）：返回新数组不改入参；
  未配对行（纯插入/多余删除）不附 segments、整行保持原语义；
  `diffStats`/`diffToText`/折叠/差异跳转均只读 type 与 text，零影响。
- 与既有能力并存：行内分段随行对象穿过折叠切片与展开渲染。
