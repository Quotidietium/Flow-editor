# 2.0.89

> 发布日期：2026-08-20
> 主题：可视化编辑器 UX 第二批——画布平移缩放、Visio AutoConnect 快连、插入图元面板、布局下拉

## 新增

- **画布平移缩放**（办公软件基本功）：Ctrl+滚轮以指针为锚缩放（40%–250%，
  工具栏右端实时显示百分比）；空格+拖拽 / 中键拖拽平移；Ctrl+H / 整理菜单
  「复位视图」回到 100%。实现为世界层 CSS transform（HTML 覆盖层随缩放一致
  变换），`svgPoint` 统一除以缩放系数，全部既有手势/框选/参考线在任意缩放下
  坐标正确
- **Visio AutoConnect 方向箭头**：单选节点四周显示四个方向箭头，点击后：
  该方向扫描带（±220px）内存在未连接节点 → 连接最近者；否则在该方向生成
  新节点 + 连线并直接进入命名编辑（draw.io drop-on-arrow 语义）；
  stateDiagram 不可表达的连线（回起点等）沿用创建期拦截
- **克隆并连接**：`Alt+Shift+方向键` 克隆选中节点到该方向并连线（draw.io
  快捷键原样采纳）
- **插入图元面板**（Visio Shapes 窗口轻量版）：工具栏「插入 ▾」按当前图类型
  列出形状/类型图元（flowchart 四形状、看板卡片/列表、C4 人员/系统…——由
  `KIND_SPECS.nodeTypes × shapes` 派生，零新增数据），点击即创建并命名；
  分组类图选中分组时插入自动挂接该组
- **布局下拉**（draw.io Arrange > Layout）：「整理 ▾」= 自动分层（原有）·
  分组排布（分组列表类专用：每组一列、组内纵向堆叠，`layoutGroupedGrid`
  纯函数）· 对齐网格 · 复位视图
