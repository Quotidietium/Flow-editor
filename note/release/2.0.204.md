## 内容

### 循环 142：示例图表网格键盘导航

- 示例图表卡片几十个类目按钮，键盘用户此前只能逐 Tab 穿越（还要
  跳过各角标钮）。现容器级委托 **←/→ 按 DOM 序、↑/↓ 按「视觉行」**
  在按钮间移动焦点——↑/↓ 用 `offsetTop` 把按钮分成视觉行并保持列位
  （flex-wrap 折行后行宽不定，按行跳比固定列数可靠）。
- **与循环 141 的历史列表 ↑/↓ 同款模式**（容器委托 + 焦点保持在
  网格内）；焦点不在网格按钮上时不劫持方向键（搜索框方向键不受
  影响）；「我的示例」「最近使用」行按钮同吃导航（容器内统一）。
- 多示例类目主钮后跟角标钮（Popover 触发器），DOM 序导航会自然
  经过它们——e2e 断言按语义目标循环推进而非写死步数。
- 网格容器加 `role="group"` + 方向键委托（a11y 告警带理由豁免：
  焦点始终在子按钮内，容器非交互目标）。
