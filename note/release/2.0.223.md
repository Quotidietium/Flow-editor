> 主题：**WEB UI 舒适度优化循环 161**——`?` 直达快捷键帮助
> （单循环批，含一处真实缺陷修复）。

## 内容

### 循环 161：按 `?` 直达快捷键帮助

- 非输入态按 `?` 直接打开应用级快捷键帮助——GitHub/VS Code 同款
  自助入口，帮助不再只藏在主菜单二级。Esc 关闭；帮助列表自文档
  化新增该条目。
- 实现：编辑页 window 键位派发 `flow-open-shortcuts` 自定义事件，
  MainMenu 监听开门（跨组件不绑死）。

### 顺带修复：Monaco 输入态守卫漏判（真实缺陷）

- 新版 Monaco 改用原生 EditContext（`div.native-edit-context`）承载
  输入，不再是隐藏 textarea——编辑页 isTypingTarget 的
  input/textarea/contentEditable 三条全漏。后果：`?` 在编辑器里
  会弹帮助；**Ctrl+E 此前在 Monaco 聚焦时也会误切可视化**（潜伏
  缺陷，同根同修）。守卫补「按 `.monaco-editor` 容器归属兜底」。
- 探针实证：焦点元素为 `DIV.native-edit-context`（isContentEditable
  为 false）。探针用完即删。
