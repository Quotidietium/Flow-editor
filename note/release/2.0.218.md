## 内容

### 循环 156：画布键盘缩放 + / - / 0

- **纯键盘用户此前无法缩放可视化画布**（滚轮缩放要 Ctrl、捏合
  要触屏）。现在画布视图下 `+`/`=` 放大、`-`/`_` 缩小（与
  Ctrl+滚轮同 1.1 步进，锚定视口中心）、`0` 复位（Ctrl+H 的
  顺手别名）——预览区 +/-/0/F（循环 148）的画布同款。
- 仅画布视图生效（列表类视图无缩放概念）；置于 isTypingTarget
  守卫之后——输入框里敲 +/- 照常是文本（e2e 用搜索框实证）。
- 帮助面板「画布视图」组同步：缩放画布 `+ / -（Ctrl + 滚轮 /
双指捏合）`、复位视图 `0 / Ctrl + H / 点击缩放读数`；缩放
  读数按钮 title 同步。
