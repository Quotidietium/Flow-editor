## 内容

### 循环 131：键盘直达 + 空态引导

- **勘误（循环 130 复盘）**：配置格式化的直达钮落地后全量 e2e 暴露
  模板菜单里**本就有**「格式化 JSON」（`formatConfigJson`）——循环
  130 的按钮实为「既有能力的直达化」而非补全（与明暗直达钮同先例，
  保留）。本循环把两处实现/文案收敛到共享 util（此前各写一份、失败
  文案不一致），测试断言同步。
- **Ctrl+O 打开本地文件**：浏览器默认的「打开」被拦截，接编辑器
  自己的打开链路——与「打开」按钮同走新提取的 `openFileIntoEditor`
  （openTextFile + loadFileIntoEditor：插件导入钩子优先、输入管道、
  配置安全门）。与 Ctrl+S 同级处理（输入态不设守卫，Monaco 聚焦时
  同样触发）；帮助对话框快捷键列表同步。Actions 的 onOpenFile 改为
  共享函数，消除双份内联。
- **预览空态引导**：画面上真的什么都没有时（清空代码后刷新、冷启动
  即无内容），预览区中央给起点提示（「在左侧输入 Mermaid 代码…/
  示例图表 / Ctrl+O」）。判定用渲染成功才清除的 `empty` 标志：
  清空但不刷新时旧图仍半透明挂着（error 态、code 记着上次渲染值），
  不给提示以免与上次内容混淆。
- **缺陷防回归记录**：`empty = false` 首版放在渲染路径开头——空代码
  时 `renderAndPlaceDiagram` 抛错进 catch（error=true）但标志已被
  提前清除，提示永不出现。移到渲染成功后（`error = false` 旁），
  探针 spec 实证前后差异。
