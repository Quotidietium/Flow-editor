## 改动

**配置模板应用可一键撤销（toast 行动钮 + 变更守卫）**

- 误点模板从此有退路：应用配置模板后，toast 挂「撤销」行动钮（8 秒窗口），一键回到应用前的配置。
- 守卫诚实不覆盖：撤销前发现配置已被再改动（手编 JSON / 换用别的模板），则不覆盖手头内容，明示「配置已变化，未撤销（可手动改回）」。
- `notify` 扩 `NotifyOptions`（`action` / `duration` 透传 svelte-sonner），签名向后兼容。
- 关键实现口径：捕获与守卫同走 `inputState.mermaid` **同步**真值——`validatedState` 是异步验证后的状态，应用瞬间用它拍不到「应用前」快照。
