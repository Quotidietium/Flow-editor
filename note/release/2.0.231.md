## 排障笔记（测试编写）

- 点 toast 行动钮属 popover 菜单外交互（interact-outside），菜单随之收起——清理/后续断言前须 Esc 保底收 + 重开，使菜单状态确定。
- 删除钮是 `stopPropagation` 独立小钮、不收菜单（动作行才有 `data-popover-close`）——菜单开着时再点触发器是 toggle 语义，会把菜单点关，后续点击撞上收摊动画（Playwright「element is not stable」→ detached）。
- 同一页面多个撤销 toast 并存时（如先应用模板再删除），`getByRole('button', { name: '撤销' })` 严格模式违例——按 toast 文本 filter 定位。
- 残留 2 例（errorDisplay:113 / mobileErrorBanner:20）为负载残留竞态，单跑分别 5s/8.6s 即过，非回归。
