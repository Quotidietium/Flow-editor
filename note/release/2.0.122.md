## 时序编辑器（SequenceEditor）

覆盖 sequenceDiagram / zenuml。时序图的两个维度天然是**有序列表**：
参与者声明顺序 = 生命线左右次序，消息顺序 = 时间先后。自由画布允许把
参与者拖到任意位置，反而摧毁这一语义——列表即正义。

- **参与者列表**：名称行内编辑、参与者/actor 类型下拉、左右移动
  （直接改变生命线次序）、删除（级联删除其消息，与画布语义一致）、
  添加（自动聚焦命名）。
- **消息列表**：源/目标下拉（目标自动排除源；改源撞到目标时交换而非
  产生无导入语法的自消息）、箭头下拉（sequence 四种 `->>`/`-->>`/`->`/
  `--)`，zenuml 两种 `->`/`-->`）、内容行内编辑、上移/下移（改变时间
  序）、删除、添加（默认前两个参与者）。
- 解析/生成零改动：参与者 = 节点数组序，消息 = 边数组序，既有
  `generateSequence`/`generateZenuml` 直接消费。
