# 2.0.70

> 发布日期：2026-08-20
> 主题：可视化编辑器移入右侧预览区（所见即所得）

## 变更

- **WYSIWYG 布局**：可视化编辑器从左侧编辑卡的第三个标签移至**右侧大预览区**——导航栏 Visual 开关在「预览渲染」与「可视化画布」之间切换右栏内容，左侧保持 Code/Config 两标签
- 解决左侧编辑窗过窄的问题：可视化画布现在占据约 70% 宽度（e2e 断言画布宽 > 700px @1920 视口）
- 预览态的悬浮工具（缩放/主题/手绘开关）仅在预览模式显示，避免与画布工具栏冲突
- 每次图形操作即时同步代码，切换模式经状态网关确定性还原图形

## 测试

- e2e `visualEditor.spec.ts` 改用导航栏 Toggle 入口，新增右栏画布宽度断言与「切回预览渲染 Start/End」的完整 WYSIWYG 回环断言
- 全量 e2e（单 worker）：42 通过 / 3 预存 skip / 0 失败；单元测试 99 通过（15 个本机预存失败与基线一致）
- svelte-check 0 错误 0 警告；eslint / prettier 通过
