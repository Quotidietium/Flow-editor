# 2.0.157

> 发布日期：2026-08-26｜分支：`develop`
> 主题：**WEB UI 舒适度优化循环 70–73**——版本号显示应用自身版本、
> 示例数角标、时序结构骨架、历史条目名双击重命名。

## 内容

### 循环 70：版本号显示应用自身版本（真修复）

- `VersionSecurityToolbar` 此前显示的是 **Mermaid 引擎库版本**
  （v11.x）——用户报障/反馈会拿错的版本号。现显示应用自身版本
  （根 package.json 编译期注入），引擎版本并入悬停 title：
  `Flow 编辑器 v2.0.x · Mermaid 引擎 v11.x`。

### 循环 71：示例类目示例数角标

- 多示例类目按钮带数量角标，一眼看出哪些类目有备选变体；
  `aria-hidden` 渲染不进可访问名（循环 31 教训——防撞按名选择器，
  e2e 内含该回归网），角标数字 = 相邻下拉项数（不变式钉住）。

### 循环 72：时序结构骨架三件套

- 插入菜单补 loop 循环 / alt-else 分支 / activate-deactivate 激活
  ——时序图最高频的三种结构，此前 7 个骨架只有声明与注释；光标处
  插入不弹整图替换。

### 循环 73：历史条目名双击/键盘直达重命名

- 名称自身即重命名入口：`role=button`+`tabindex`+Enter/Space/双击
  全可达（MC 树行同款模式——不触 a11y 静态警告、不与 eslint 空豁
  免打架）；铅笔按钮保留为视觉发现路径。
