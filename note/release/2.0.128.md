# 2.0.128

> 发布日期：2026-08-22
> 主题：插件管理器重写（导入/导出/启停/详情/模板库）+ MCP 服务管理器（桌面版 HTTP 端口配置）

## 内容

### 插件管理器（`PluginManager.svelte` 重写，三标签页）

- **已安装**：插件卡片含名称/版本/本地化权限徽章/状态徽章（已启用、
  已停用、连续出错计数）；Switch 启停；**两步确认卸载**（点击武装 →
  「确认卸载？」，3 秒自动复位）；**导出**按钮把持久化源码下载回
  `<id>.mjs`；**详情页**（对话框内二级视图）：完整清单、本地化权限说明、
  运行时钩子与摘要（导入扩展名/导出标签/前端 URL/主题变量数）、源码
  预览、存储命名空间、模块加载状态、安装时间。
- **模板库**（新增 `src/lib/plugins/templates.ts`）：6 个注释详尽的
  细化模板——输入清洗 / PlantUML 导入 / CSV 导出 / 海洋主题 / 图表
  仪表盘前端（data: 内嵌页 + 桥双向调用演示）/ AI 提示词导出。一键
  安装（同 id 拒绝并显示「已安装」）或下载 `.mjs` 自行改造。
- **MCP 服务**（新增 `McpManager.svelte`）：postMessage 桥状态、六个
  工具清单与调用示例（一键复制）；HTTP 服务的启用开关 + 端口配置 +
  运行状态徽标 + curl 接入示例。

UI 从手写 overlay 迁移到 shadcn `Dialog`（与「分享」一致），键盘事件
隔离不穿透到画布。registry 新增 `getPluginRuntime()`（详情页数据源）
与 `exportPluginSource()`（仅持久化源码可导出，运行时注册实例返回
undefined）。

### MCP HTTP 服务（桌面版，默认关闭）

- 页面侧 `mcpConfig.ts`：端口校验（1024–65535）、不可信配置硬化、
  localStorage 持久（web 端记忆偏好）；桌面版经
  `window.__FLOW_DESKTOP__.mcp`（新增 `preload.cjs` contextBridge，
  仅三个方法的最小 IPC 面）读写真实配置。
- 主进程 `mcp-server.cjs`：把页面 MCP 桥暴露为
  `http://127.0.0.1:<port>/`（默认 38528）。安全面：仅回环、仅 POST、
  强制 `application/json`（跨域简单请求防线，不输出 CORS 头）、6MB
  请求上限（超限 413 后排空余量，连接不 RST）、batch 拒绝、执行器
  15s 超时；配置主进程二次校验后存 `userData/mcp-config.json`。
- 请求经 `executeJavaScript` **双重 JSON 编码**调用页面
  `__FLOW_EDITOR_BRIDGE_CALL__`（JSON.parse 还原）——请求内容永不以
  代码身份被求值。
- `build.ps1` 打包前运行 `scripts/test-mcp.mjs`（13 项协议/安全探测）；
  `smoke.mjs` 新增 5 项 MCP 端到端探测（预写 userData 配置启动，测后
  还原现场）。

### 工具链修复（预存问题）

- `eslint.config.js`：`includeIgnoreFile` 只读根 .gitignore，installer
  构建产物（app/site/dist/.cache/.smoke）在本机存在时 `eslint .` 会扫
  入压缩 bundle 报 4.6 万条假错误——已加入 `globalIgnores`；`.cjs` 关闭
  `no-require-imports`（CommonJS 合法形式）。修复后仓级 eslint 归零
  （含 stress-smoke.mjs 空箭头、main.cjs 未用指令两处预存）。
- 已知本机环境项（非本次引入）：`prettier --check` 对 CRLF 检出
  （core.autocrlf=true）全仓误报，CI Linux（LF）为绿；本机改动文件均
  经 lint-staged 验证。
