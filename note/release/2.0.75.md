# 2.0.75

> 发布日期：2026-08-20
> 主题：可视化编辑器多图类型支持（时序图 / 类图 / 状态图 / ER 图 / 思维导图）

## 新增

- **六类图可视化编辑**：通过「图表类型适配层」（`VGraph.kind` + `KIND_SPECS` 能力表 +
  每类 parse/generate），Visual 标签现在直接导入并编辑 **flowchart、sequenceDiagram、
  classDiagram、stateDiagram(-v2)、erDiagram、mindmap**——切换 Visual 即解析当前代码，
  所有图形操作经状态网关实时生成对应类型的 Mermaid 源码（不再只有流程图可用）
- 类型感知工具栏：添加按钮随类型变化（节点/参与者/类/状态/实体）；状态图起点/终点按钮；
  线型/形状循环使用每类调色板（类图 8 种关系、时序图 4 种箭头）；ER 基数循环；
  类成员/ER 属性/状态描述的详情编辑器；方向开关仅在 mermaid 支持的类型显示
- 画布渲染：详情行使节点高度自适应；起止伪节点（实心圆/双圈）；按线型区分的箭头
  （实心/开箭头/三角）与组合/聚合源端菱形；虚线线型；ER 基数沿线标注
- 不支持的图类型（gantt/pie 等）toast 明确列出支持范围

## 正确性保障

- 每类图「往返不动点」单测（首次生成允许格式归一化）；**全部生成代码经真实
  `mermaid.parse` 验证合法**；flowchart 金样随 `kind` 字段更新
- 时序图消息正则用惰性参与方量词（贪婪 `\S+` 会把 `Bob-->>Alice` 拆成 `Bob-`+`->>`）；
  类图基数强制带引号避免与 `o--` 歧义；思维导图按原始缩进弹栈建树
- 修复：类图调色板补「箭头关联」（解析出的 `-->` 边此前无循环项）；标签编辑器改用
  挂载 action 聚焦（autofocus 属性在工具栏点击后不夺焦，Enter 会误触按钮）

## 测试

- 新增 20 个单测（`model.multikind.test.ts`）+ 2 个 e2e（时序图/类图导入-编辑-往返）
- 全量 e2e：41 通过 / 3 预存 skip / 0 失败；单测 145 通过（15 个本机预存失败与基线一致）；
  svelte-check 0/0；eslint / prettier 通过
- e2e 经验：向 Monaco 输入代码用剪贴板粘贴（逐字符键入 `(` `)` 与状态同步有竞态会丢键）；
  垂直连线的命中 path 几何宽度为 0（Playwright 判定不可见），点击连线用节点盒中点绝对坐标
