# 2.0.138

> 发布日期：2026-08-24｜分支：`feat/jar-export-menu`（基于 develop）
> 主题：**MC 进度设计器默认安装**——编辑器开箱即用，网页版与桌面安装包
> 一致（含 2.0.137 的一键 JAR 导出项）。

## 内容

### 内置插件机制（registry）

- **首次播种**：`loadRegistry` 启动时把捆绑的 MC 进度设计器
  （`flow.mc-advancement` v1.10.0）写入插件注册表，默认启用——
  新用户/新环境零操作可用（导航栏 插件 → 打开 MC 进度设计器 /
  导出菜单两个导出项）。
- **升级刷新**：应用升级后捆绑源码与 manifest 覆盖存储副本，
  **保留用户的启用/停用选择**（停用不复活）；用户曾手动安装同 id
  旧版本也会被收编为内置（不产生重复记录）。
- **不可卸载**：内置插件仅可停用（管理器卡片/详情隐藏卸载按钮，
  `uninstallPlugin` 同步守卫）；重复安装同 id 仍被「已安装」拒绝。
- **源码内嵌方式**：`src/lib/plugins/builtin/mc-advancement.mjs` 为
  canonical（`plugins/examples/`）的逐字节副本，经 `?raw` import 进
  bundle——网页构建与桌面安装包（robocopy 整站同步）天然同源。
  副本原因：Vite dev fs 中间件拒绝 src 外的 ?raw 请求（403 实测）；
  **字节一致性由单测守卫钉住**（改插件必须同步两处，测试即拦）。

### 载入路径统一（附带）

- `loadModule` 从 blob URL 改为 data: URL 动态 import——jsdom 无
  `URL.createObjectURL`，注册表全部路径（安装/播种/启用）从此可单测。
