> 发布日期：2026-08-21
> 主题：本地文件保存/打开与多格式导出（.mmd / PNG / SVG / WebP / JPEG / PDF / Markdown / 状态 JSON）

## 新增

- **操作卡片重构**：
  - 「保存」：当前 Mermaid 源码下载为 `.mmd` 文件（时间戳文件名）
  - 「打开」：选择本地 `.mmd`/`.md`/`.txt`/`.json` 文件载入编辑器——`.json`
    状态文件恢复源码+配置；Markdown 自动剥离 ```mermaid 代码块；无法识别
    的内容 toast 提示
  - 「导出 ▾」菜单（选择后自动收起，点击外部关闭）：
    - **PNG / SVG**（原有能力收纳入菜单，PNG 尺寸选项保留）
    - **WebP / JPEG**（新增位图格式，canvas 输出，质量 0.95）
    - **PDF**（新增，jsPDF 按图形宽高比自动横竖版；依赖懒加载不进启动包）
    - **Markdown**（新增，```mermaid fenced 代码块 .md）
    - **Mermaid 源码（.mmd）**（与「保存」同源）
    - **状态文件（.json）**（新增，源码+配置+版本号，供「打开」完整恢复）
- 新增 `src/lib/util/fileIO.ts`：`diagramFileName`（时间戳命名）、
  `markdownOf`/`stateFileOf`（纯构造器）、`parseOpenedFile`（.json 状态/
  .md 剥离代码块/裸源码三分支解析）、`downloadTextFile`（base64 data URL
  通道——与 SVG 导出一致，blob 下载在部分内嵌 Chromium 无法捕获）
- 复制图像保留不变
