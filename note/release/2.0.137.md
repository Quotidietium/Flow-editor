# 2.0.137

> 发布日期：2026-08-24｜分支：`feat/jar-export-menu`（基于 develop）
> 主题：MC 成就插件导出菜单新增「一键编译 .jar」——装好 JDK 21+ 的
> 桌面版无需打开设计器面板、无需 Maven，导出菜单直接出可安装 jar。

## 内容

### 平台：插件多导出项 + 异步导出

- **`exports: ExportFormat[]`**（新字段，优先于旧单 `export`——两者
  并存时旧字段忽略不重复）：一个插件可注册多个导出菜单项，每项
  独立 id/label/testid（`plugin-export-<id>`）。
- **`run` 可为 async**：`runPluginExport` 改经 `guardedAsync`（异步
  rejection 与同步异常同样三振隔离）；Actions 的菜单点击路径异步化
  并兜底 catch 提示。
- 向后兼容：旧单 `export` 插件行为不变（既有 e2e zip 下载用例原
  testid 保持）。

### 插件：MC 设计器双导出项（v1.10.0）

- 导出菜单新增「MC 成就插件（编译 .jar·桌面版+JDK21+）」：
  - **桌面版**：宿主页直调 preload `__FLOW_DESKTOP__.mcBuild.build`
    （与前端面板按钮同一后端：白名单校验→javac --release 21→jar），
    base64 → Blob 一键下载，toast 报 JDK 版本；
  - **未装 JDK**：主进程结构化错误文案（JDK_NOT_FOUND/JDK_TOO_OLD
    引导）透传；
  - **网页版**：提示「仅在桌面版可用（网页无法运行 javac）」并
    指引 mvn package 路径；
  - **图非法**：编译前校验拦截，提示首个错误。
- 走 notify 而非 throw（引导类提示不计三振，避免三次点击停用插件）。
