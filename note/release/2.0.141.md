# 2.0.141

> 发布日期：2026-08-25｜分支：`develop`
> 主题：**WEB UI 舒适度优化循环 1–5**——配置模板一键部署为首的五项
> 体验细化，全部经真实浏览器 e2e 验证。

## 内容

### 循环 1：配置模板预设（一键部署）

- 配置标签页头部新增「模板」菜单：**风格 / 主题 / 版式** 三组共 12 个
  预制配置片段（手绘风格、经典线条；默认/深色/森林/中性/Neo/Neo 深色
  六主题；紧凑布局、宽松布局、演示大字、打印白底）。
- **深合并**写入：同名标量覆盖、对象递归、数组替换——用户既有配置键
  全部保留；JSON 损坏时不做任何写入并提示。
- 菜单底部另含「格式化 JSON」与「重置为默认」。
- 纯逻辑层 `src/lib/util/configPresets.ts`（注册表加载期自检：id 唯一、
  theme/look 枚举合法），单测 13/13。

### 循环 2：历史记录搜索过滤

- 历史面板顶部搜索框，同时匹配**条目名称与图表代码内容**（默认名是
  随机英文 slug，匹配代码中的中文标签/节点 id 才实用），大小写不敏感。
- 无匹配提示；Esc / 清空按钮恢复全量。

### 循环 3：编辑器自动换行切换

- 编辑器卡片头部新增换行开关（代码/配置共用），Monaco 与 CodeMirror
  双端生效；偏好持久化 `editorWordWrap`，跨会话保持。
- **深坑并修（防回归记录）**：
  1. `$effect` 首跑早于 `onMount` 的 editor 创建——持久化偏好为开时
     丢一次应用（构造参数 / compartment 初始值补齐）。
  2. `$effect` 内 `editor?.updateOptions(wordWrap…)` 的 **`?.` 短路令
     首跑永远读不到 wordWrap**——Svelte 依赖追踪只订阅实际执行到的
     读取，切换永不触发。修复：先无条件读取再 `?.`。
     （排查期 console.log 恰好读了它，造成"时好时坏"假象。）

### 循环 4：PNG 尺寸快捷预设

- 宽/高模式下显示 720 / 1080 / 1440 / 2160 四档 chips 一键填入
  （选中态高亮），自动模式隐藏。

### 循环 5：可视化编辑器快捷键帮助

- 工具栏新增「?」按钮打开对话框：画布 / 选择 / 编辑 / 历史与视图 /
  专用编辑器五组共 24 项快捷键与鼠标操作，与 `onWindowKeydown`
  实际实现逐项对应。
