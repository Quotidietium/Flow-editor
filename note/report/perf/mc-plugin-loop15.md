# MC 进度设计器：性能 / 桌面链路 / 无障碍终审（循环 15，2026-08-23）

> 版本基线：v2.0.135（mc-advancement 1.7.0）。三项新维度终审的数据与结论。

## 1. 前端核心性能（大图压力）

样本：6 栏 × N/6 长链（深 parent 链 + 多栏的最坏形态），Node 26 直跑
coreFactory（与浏览器同引擎）。结论：**全部线性量级，无优化必要**。

| 节点数 | analyze | exportZip | buildJarRequest |
| -----: | ------: | --------: | --------------: |
|    100 |  3.4 ms |    7.5 ms |          3.0 ms |
|    300 |  3.0 ms |    8.7 ms |          5.6 ms |
|    600 |  4.8 ms |   15.9 ms |         12.0 ms |

600 节点全链路 <35ms；前端 onchange 失焦触发（非击键级），远低于可感
阈值。树渲染为一次性 innerHTML 拼接（数百行 DOM 一次布局），无逐行
reflow。

## 2. 桌面编译链（mc-build.cjs）

- **并发**：两路 `build()` `Promise.all` 实测 2.2s 双 jar 成功——每次
  构建 `mkdtemp` 独立工作目录 + 参数数组 spawn，天然无共享态冲突。
- **错误面**（已由 test-mc-build 13/13 钉住）：路径穿越/绝对路径/空清单/
  缺 java 源/缺工具链/坏 javac 回退/JDK 缺失与过旧引导/javac 失败尾部
  12 行回显/jar 打包失败。
- **已知边界（记录不修）**：MCP HTTP 执行器共享 60s 超时，而 javac 上限
  120s——超慢机器经 HTTP 路径会先超时（错误可读、无副作用：编译进程
  继续完成即退出）；前端按钮路径（90s）不受影响。成果 jar 无缓存——
  服务器插件场景一次一个，缓存无收益。

## 3. 无障碍（插件前端面板）

- 树行/栏头此前仅鼠标可达（div 无焦点）。现补 `tabindex="0"` +
  `role="button"` + `aria-pressed`（选中态）+ Enter/Space 激活
  （`preventDefault` 防滚动）——键盘可完成「浏览树 → 选中 → 表单编辑」
  全流程；e2e 以 `focus()+press('Enter')` 断言键盘选中打开属性表单。
- 表单 label 均为包裹式绑定（原生可聚焦控件）；主应用侧为 shadcn 组件
  （自带语义），不在本插件审计范围。
